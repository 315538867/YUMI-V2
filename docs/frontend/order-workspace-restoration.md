# 订单工作区还原施工清单

- 原型：`orders-element-plus.html`
- 范围：订单列表、新建订单、订单详情五个页签及收退款/发货交互
- 视觉：保持当前全白后管样式，只还原原型的信息层级、页签和操作流程
- 不在本清单：订单备注（普通订单无字段）、订单取消、财务一体工作台、其他模块

## 1. 原型对照

| 原型界面 | 当前实现 | 结论 |
|---|---|---|
| 订单列表：应收/净收款/交付与付款履约分列 | 列表有状态、应收、交付/付款，缺客户与净收款 | 补齐列 |
| 新建订单：客户与交付、商品与成交约定（多明细）、本次订单 | 单明细表单，直接保存 | 重做为多明细整页 + 确认预览 |
| 详情：成交约定 | 单页订单项表 | 新页签 |
| 详情：生产进度 | 无 | 新页签，关联需求/合格完成/已发货/状态 |
| 详情：发货记录 | 仅发货弹窗 | 新页签 + 发货更正 |
| 详情：收退款记录 | 仅收款/退款弹窗 | 新页签 + 预览确认 + 凭证查看 |
| 详情：订单记录 | 无 | 新页签时间线 |
| 收款/退款：登记 → 核对预览 → 确认 | 单步弹窗直接提交 | 两段式 |
| 凭证上传/查看 | 上传有，查看无 | 增加查看 |
| 发货更正 | 后端命令有，页面无 | 增加更正入口 |

## 2. 后端读模型

### 2.1 orders 工作区查询

`GET /api/orders/{orderBusinessId}/workspace`

返回：

- `order`：现有 `OrderView`
- `customerSnapshot`：客户快照（编号、名称、联系人、电话、地址）
- `items[]`：
  - 订单项与当前生效约定
  - 商品快照名称
  - 方案快照名称/目标工序/售价
  - 生产进度：需求标识、需求数量、合格完成、已发货、状态
- `shipments[]`：
  - 发货头（单号、日期、物流单号、有效状态）
  - 发货明细（明细标识、订单项、数量、有效数量）
  - 更正记录（类型、数量变化、原因、时间）
- `paymentLinks[]`：
  - 订单支付关联（现金事实标识、收/退、冲销、金额、发生时间、有效状态）
- `events[]`：
  - 确认、变更、发货、收退款、完成事实按时间排序

依赖方向：`orders → customer, product, production`，符合基线 03。

### 2.2 finance 现金凭证查询

`GET /api/finance/cash/facts/{cashFactBusinessId}`

返回现金事实与凭证文件标识；凭证内容仍由现有文件读取接口按权限读取。

`orders` 不依赖 `finance`，支付行由 orders 工作区返回关联标识，前端按需查 finance 凭证。

### 2.3 不改表

- 不新增订单备注列
- 不新增取消订单命令
- 不复制原型 localStorage 数据逻辑

## 3. 前端改造

### 3.1 订单详情五页签

- 页头：订单号、状态、日期、发货/收款/退款操作
- 概览：应收、已收、已退、交付履约、付款履约、阻断原因
- 成交约定：订单项、商品/方案快照、目标工序、数量、单价、供料来源、收货信息
- 生产进度：每项需求、需求数量、合格完成、有效已发货、需求状态
- 发货记录：可发数量、发货记录、有效数量、发货更正
- 收退款记录：收退款流水、有效性、凭证查看
- 订单记录：确认/变更/发货/收付/完成时间线

### 3.2 收退款

- 登记弹窗：金额、日期、说明、凭证
- 核对预览：订单/客户、金额、日期、说明、凭证
- 确认后才提交现金命令

### 3.3 发货

- 发货记录查询与更正
- 更正必须填写原因；原记录保留，只计最新有效数量

### 3.4 新建订单多明细

- 客户与交付（订单级）
- 多条商品与成交约定：每项独立商品/方案/目标工序/数量/单价/供料来源
- 共用收货信息（与原型一致）
- 本次订单汇总 + 确认预览后提交

## 4. 验收

- 原型逐屏对照：五个页签、两段式收退款、凭证查看、发货更正、多明细录入均可见可操作
- 列表净收款列、订单说明（建单/预览/详情）已补齐
- 后端：工作区查询、发货记录、时间线、凭证查询集成测试
- 前端：typecheck、单测、构建
- E2E：订单详情五页签、收退款预览、发货更正、多明细建单
- 不出现空壳页签；无数据时有明确空态

## 5. 实施顺序

1. orders 工作区读模型 + finance 凭证查询
2. 订单详情五页签 + 收退款预览/凭证 + 发货更正
3. 新建订单多明细 + 确认预览
4. 列表列补齐与逐屏截图验收

# 原型差距补齐施工清单

- 原型：仓库根目录 `customers/workforce/product/production/orders/finance-element-plus.html`
- 原则：原型只作布局与流程参考，字段与业务规则以 `docs/一期` 为准；不改已确认的业务模型。
- 顺序：人员与小组历史 → 商品详情 → 生产建单页 → 财务工作台。

## 1. 人员与小组历史与标准版本

- [x] 员工详情新增“就业记录、资格变更、活动引用”页签。
- [x] 小组详情新增“成员变更、状态记录、活动引用”页签。
- [x] 人员标准显示当前版本、活动引用数，并提供版本记录。
- [x] 标准修改记录调整说明；版本只追加，不覆盖历史。
- [x] 后端新增历史查询接口；团队状态事实与标准版本事实落表。
- 验收：新建/离职/返聘、资格授予/撤销、成员调整、停用、标准修改后，详情与版本记录可追溯；活动引用为空时显示明确空态。

## 2. 商品详情按原型分区

- [x] 预算条：标准售价、工作室承担成本、预计利润、日产能。
- [x] 基本规格、基础材料、三道工序参数、额外单件费用分区展示。
- [x] 方案表补材料来源、状态与启用/停用操作。
- 验收：只读展示完整商品定义；标准方案不可编辑，自定义方案可编辑/启停。

## 3. 生产新建任务独立页面

- [x] 新建任务从弹窗改为 `/production/tasks/new` 独立页面。
- [x] 左侧可安排来源池、右侧已选来源，同工序校验与可安排数量提示。
- [x] 保存后进入任务详情；其他任务保持现有字段。
- 验收：正常生产、制作超额、返工/其他任务可创建；来源数量与工序校验由后端最终确认。

## 4. 财务工作台与预览抽屉

- [x] 财务模块提供统一工作台入口，含月度汇总、资金收付、成本台账、工资结算入口。
- [x] 日常收支登记先核对预览再提交。
- [x] 成本与现金记录提供详情抽屉，现金详情可查看凭证。
- 验收：月度汇总不称利润；预览可返回修改；抽屉只读且凭证按权限读取。

## 不做

- 不照搬原型 localStorage、示例数据与 CDN 依赖。
- 不新增原型中未进入一期规格的账户、仓库余额或自动激励金额。
- 不修改已完成的订单五页签和客户页面。

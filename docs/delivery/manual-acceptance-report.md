1. **导出字段**：发货台账导出**不含**物流公司/单号/运费/发货备注（物流字段只在发货详情与打印显示）——这是既定口径，不是缺陷。

4. **关闭条件**：报废、余量或生产完成**不能单独**触发关闭（既定口径）。

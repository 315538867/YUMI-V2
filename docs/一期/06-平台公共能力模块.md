# 平台公共能力模块

> 模块代码：`platform`

## 1. 模块说明

平台模块为所有业务模块提供身份、权限、请求上下文、幂等、审计、文件和提交后任务等非业务公共能力。平台只保证“谁在什么请求中做了什么”，不替代业务模块判断“该动作是否业务合法”。

## 2. 一期需求和范围

### 2.1 一期提供

- 管理端账号登录、退出和会话管理；
- 角色、权限点和账号授权；
- 当前操作者、请求编号、业务时区等请求上下文；
- 正式写请求幂等；
- 操作审计和敏感数据访问审计；
- 文件上传、校验、正式化、引用和删除保护；
- 事务提交后的可重试任务，用于报表刷新等非强一致工作。

### 2.2 一期不提供

- 业务对象通用 CRUD；
- 通用审批流和工作流；
- 业务快照中心、业务事实中心；
- 跨模块事务编排；
- 自定义字段平台；
- 外部开放平台和第三方 OAuth。

## 3. 模块功能

1. `authenticate`：校验账号凭证并创建会话；
2. `authorize`：判断权限点和资源范围；
3. `beginIdempotentCommand`：登记命令幂等执行；
4. `completeIdempotentCommand`：保存成功结果摘要；
5. `recordAudit`：记录操作对象、动作和结果；
6. `createUpload` / `formalizeFile`：管理临时上传到正式文件；
7. `attachFileReference` / `releaseFileReference`：维护文件引用计数；
8. `enqueueAfterCommitTask`：事务提交成功后登记异步任务；
9. `claimAndExecuteTask`：带租约执行可重试任务。

## 4. 模块边界

### 4.1 平台拥有

账号、角色、权限、会话、幂等记录、审计日志、文件元数据、文件引用、提交后任务。

### 4.2 平台不拥有

员工业务资料、商品图片业务用途、订单附件语义、生产证据语义、财务凭证语义。业务模块只保存平台正式文件标识和用途关系，文件内容仍由平台管理。

## 5. 业务规则

- 账号与员工是不同概念；需要时通过稳定员工标识关联。
- 权限点使用稳定代码，禁止根据页面按钮名称判断权限。
- 正式写命令必须先完成认证、权限和幂等校验。
- 临时文件不能被业务记录正式引用；正式化与业务提交必须处于同一事务语义中。
- 已被业务引用的正式文件不能直接物理删除。
- 审计日志不可编辑；错误补充通过关联说明记录，不覆盖原日志。
- 提交后任务失败不回滚已提交业务，但必须可重试、可观察和可人工恢复。

## 6. 状态设计

- 账号：`ACTIVE / LOCKED / DISABLED`；
- 会话：`ACTIVE / EXPIRED / REVOKED`；
- 文件：`TEMPORARY / FORMAL / QUARANTINED / DELETED`；
- 幂等执行：`PROCESSING / SUCCEEDED / FAILED`；失败记录只用于诊断，不作为成功结果；
- 提交后任务：`PENDING / RUNNING / SUCCEEDED / RETRY_WAIT / DEAD`。

密码只保存强哈希；令牌只保存哈希；审计中的敏感字段必须脱敏。

## 9. 事务与并发

- 幂等成功记录、业务写入和审计结果必须同事务提交；
- 文件正式化失败时业务关联不得提交；
- 任务租约通过条件更新领取，避免多 worker 重复执行；
- 登录失败计数、账号锁定和会话吊销采用行版本或条件更新；
- 同一文件的正式引用增加/减少必须防止负引用数。

## 10. 权限、审计与错误

核心权限：`platform.account.manage`、`platform.role.manage`、`platform.audit.read`、`platform.file.upload`、`platform.task.manage`。

稳定错误码：`AUTHENTICATION_REQUIRED`、`ACCOUNT_DISABLED`、`PERMISSION_DENIED`、`IDEMPOTENCY_CONFLICT`、`FILE_NOT_FORMAL`、`FILE_IN_USE`、`TASK_LEASE_CONFLICT`。

## 11. 页面与交互要求

- 登录页；
- 账号和角色管理页；
- 审计检索页；
- 文件上传统一组件；
- 提交后任务监控页，仅管理员可见。

业务页面按钮隐藏不能代替后端权限校验。

## 12. 验收标准

- 重复相同命令返回同一业务结果；不同输入复用幂等键被拒绝；
- 未授权账号无法通过直接请求执行操作；
- 业务事务回滚时不留下成功幂等和成功审计；
- 正式文件引用可追踪，引用中的文件不可删除；
- 多 worker 不会同时执行同一任务；
- 敏感字段不会以明文出现在日志和审计详情。

## 13. 待确认问题

本模块当前无阻塞一期开发的业务问题。密码策略、会话时长和文件大小上限属于部署参数，在开发前由运行配置确定。

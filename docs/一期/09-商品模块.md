# 商品模块

> 模块代码：`product`

## 1. 模块说明

商品模块独立管理商品制作规格、固定工序字段、单件额外费用、内置标准方案、多个自定义方案、预算结果和对外业务快照。它不是基础资料模块的附属部分。

## 2. 一期需求与模块功能

录入商品时，一次提交以下完整内容：

```text
商品
├─ 基本字段
├─ 制作工序字段
├─ 捏毛装袋工序字段
├─ 缝边剪袋工序字段
└─ 额外单件费用
```

提交成功后系统自动生成内置标准方案并完成预算计算。后续编辑商品时，内置标准方案自动同步；用户可以另外建立多个自定义方案。

## 3. 本期范围

### 3.1 本期提供

- 商品创建、编辑、停用和查询；
- 商品图片的正式文件引用；
- 固定结构的三类工序字段；
- 商品单日最大产能参数；
- 内置标准方案自动生成和同步；
- 自定义方案创建、编辑、停用；
- 只读预算预览和正式预算结果；
- 商品及方案快照的创建或复用。

### 3.2 本期不提供

- 通用材料目录；
- 任意增加工序或动态字段；
- 库存、采购、领料；
- 装箱生产工序；
- 服务端草稿；
- 方案“默认选择”字段；
- 用户独立编辑内置标准方案。

## 4. 商品字段

### 4.1 基本字段

| 字段 | 含义和规则 |
|---|---|
| 商品编号 | 系统生成，创建后不可修改或复用 |
| 商品名称 | 必填，可重名，以商品编号区分 |
| 商品说明 | 可选，不参与公式 |
| 单件标准克重 | 必填且大于 0 |
| 制作星级 | 从基础资料选择；名称和标准分钟写入商品，不动态引用 |
| 单件标准制作分钟 | 由星级带出并保存，后续静态数据变化不自动更新 |
| 标准售价 | 内置标准方案售价 |
| 胶水损耗率 | 默认值仅预填，提交后写入商品 |
| 胶水单价 | 每克单价；默认值仅预填，提交后写入商品 |
| 色浆单价 | 每克单价；默认值仅预填，提交后写入商品 |
| 制作提成 | 单件制作人工成本，属于商品，不允许方案自定义 |
| 模具数量 | 必须大于 0 |
| 模具每日生产批次 | 每个模具每日标准批次数，必须大于 0 |
| 状态 | `ACTIVE / INACTIVE` |

```text
商品单日最大产能 = 模具数量 × 模具每日生产批次
```

公式由计算中心执行，商品模块保存输入和计算结果。

### 4.2 制作工序字段

| 字段 | 规则 |
|---|---|
| 单件标准制作分钟 | 来自商品基本字段，方案中只读 |
| 单件制作提成 | 人力成本，商品级维护，方案中只读 |
| 其他材料费用 | 单件金额，可在自定义方案中替换 |

胶水用量按“单件标准克重 ×（1 + 损耗率）”计算；胶水成本和色浆成本都使用该用量分别乘各自每克单价，色浆不重复计算损耗。公式由计算中心执行，不建立通用材料明细。

### 4.3 捏毛装袋工序字段

| 字段 | 规则 |
|---|---|
| 单件标准分钟 | 由静态选项带出后保存到商品 |
| 单件人工成本 | 商品级维护，方案中只读 |
| 单件袋子成本 | 直接录入单件金额，不录入袋子数量和单价拆分 |
| 单件装饰品价格 | 直接录入单件金额 |
| 单件其他费用 | 本工序除人工、袋子和装饰品外的金额 |

本工序不设置“是否包含”。是否执行由方案的目标工序决定。

### 4.4 缝边剪袋工序字段

| 字段 | 规则 |
|---|---|
| 单件标准分钟 | 由静态选项带出后保存到商品 |
| 单件人工成本 | 商品级维护，方案中只读 |
| 单件综合材料成本 | 缝线等材料合并录入，不单列来源 |
| 单件其他费用 | 本工序其他金额 |

该工序没有客户供料选项，不设置缝线来源。

### 4.5 额外单件费用

以下字段均为已经分摊到每件商品的金额，直接录入，不由商品模块再次分摊：

| 字段 | 说明 |
|---|---|
| 其他任务人工费 | 打包发货等非三类生产工序的单件人工费，不是制作提成 |
| 运输包装费 | 外层运输包装等单件费用 |
| 日常杂费 | 已分摊单件金额 |
| 房租水电费 | 已分摊单件金额 |
| 模具单件摊销费 | 已计算完成的单件摊销金额 |
| 其他费用 | 不能归入以上项目的单件金额 |

装箱/打包发货不作为生产工序，其费用放在额外单件费用中；如果需要安排实际工作，由排班的“其他任务”处理。

## 5. 方案设计

### 5.1 统一结构

内置标准方案和自定义方案使用同一套结构：

```text
方案级字段
├─ 方案名称
├─ 商品克重（继承，只读）
├─ 目标工序
├─ 售价
├─ 胶水来源
└─ 色浆来源

目标工序范围内的工序字段
├─ 制作工序
├─ 捏毛装袋工序（目标到此或更后）
└─ 缝边剪袋工序（目标到此）
```

目标工序就是本方案的最后一道生产工序，只能为：`MAKING`、`BAGGING`、`SEAM_CUTTING`。

### 5.2 内置标准方案

- 商品创建时自动生成；
- `scheme_type = SYSTEM_STANDARD`；
- 不是交互意义上的“默认选项”，不设置默认选择字段；
- 不允许用户独立编辑或删除；
- 商品基本字段、工序字段或额外费用变化时自动同步；
- 售价使用商品标准售价；
- 胶水、色浆、袋子和装饰品来源均为工作室；
- 目标工序为商品标准交付的最后一道工序，商品编辑时一并提交。

### 5.3 自定义方案

- `scheme_type = CUSTOM`；
- 与内置标准方案使用相同表结构、完整工序字段和计算模型，不另建“自定义方案专用结构”；
- 方案级可修改：名称、目标工序、售价、胶水来源、色浆来源；
- 制作工序可修改：其他材料费用；
- 捏毛装袋可修改：袋子成本、袋子来源、装饰品价格、装饰品来源、其他费用；
- 缝边剪袋可修改：综合材料成本、其他费用；该工序无来源选项；
- 商品克重、各工序标准分钟、制作提成和各工序人工成本由商品同步到方案，只读；
- 商品额外单件费用由商品同步到方案，只读；
- 自定义方案的可编辑字段变化，或者商品同步导致方案有效内容变化时，都递增方案 `content_version`。

材料来源只有：`STUDIO`、`CUSTOMER`。客户提供材料时仍保留标准资源价值和用量计算，但不计入工作室承担成本。

## 6. 预算规则

### 6.1 成本范围

```text
方案总成本输入
= 商品基本字段推导的胶水、色浆成本
+ 目标工序范围内的工序成本
+ 商品额外单件费用
```

- 内置方案使用商品工序字段；
- 自定义方案只替换允许自定义的工序成本和材料来源；
- 人工标准、制作提成、各工序人工成本和额外单件费用始终继承商品；
- 计算公式全部由 `calculation` 提供；商品模块不复制公式；
- 商品模块保存当前预算结果、计算规则版本和输入指纹。

### 6.2 输出

- 全资源单件成本；
- 工作室承担单件成本；
- 客户提供材料标准价值；
- 预计单件收入；
- 预计单件利润；
- 预计利润率；
- 分项成本明细。

## 7. 模块边界

### 7.1 商品模块拥有

商品当前定义、工序配置、额外费用、方案当前定义、预算结果和商品/方案快照。

### 7.2 商品模块不拥有

静态数据当前值、订单成交事实、生产事实、排班任务、成本台账、现金事实和工资结果。

### 7.3 上游和下游

- 调用 `base-data` 取得录入默认值和静态选项；提交时把必要值写入商品；
- 调用 `calculation` 计算产能和预算；
- 调用 `platform` 管理图片引用、幂等和审计；
- 向 `orders` 提供商品/方案当前快照；
- 向 `scheduling` 提供包含商品快照引用、工序标准分钟、人力成本和单日产能的正式排班引用；关联商品的其他任务另取得包含商品快照引用和其他任务单件人工费的正式引用；页面预览另走只读查询。

## 8. 状态设计

- 商品：`ACTIVE / INACTIVE`；
- 方案：`ACTIVE / INACTIVE`；内置方案随商品状态，不单独停用；
- 预算结果没有业务状态，始终对应当前内容版本；
- 快照不可修改，只能产生新版本。

停用商品或方案只禁止新业务引用，不影响历史订单和快照解析。

## 10. 业务流程

### 10.1 创建商品

```text
读取基础资料默认值仅用于页面预填
→ 用户一次提交完整商品
→ 校验固定字段和目标工序
→ 调用计算中心计算单日产能
→ 写商品、三类工序和额外费用
→ 自动生成内置标准方案
→ 调用计算中心计算预算
→ 写预算结果、文件关系、幂等和审计
→ 一次提交
```

### 10.2 编辑商品

```text
锁定商品并校验 row_version
→ 校验是否有不允许变更的业务限制
→ 更新完整商品聚合
→ content_version + 1
→ 完整同步内置标准方案并递增其 content_version
→ 只同步各自定义方案的继承只读字段，保留其可编辑字段
→ 对有效内容发生变化的自定义方案递增 content_version
→ 重算内置方案及所有受商品继承字段影响的自定义方案
→ 一次提交
```

已有历史快照不修改。

### 10.3 创建或编辑自定义方案

一次提交完整方案；商品模块装配并保存完整方案结构，校验目标工序和来源，只接受允许编辑的字段，把当前商品只读字段写入方案，重算预算并递增方案内容版本；不创建服务端半成品。

### 10.4 取得当前快照

- 商品快照：比较 `product.content_version`；相同版本存在则复用，否则创建；
- 方案快照：同时比较 `scheme.content_version` 和 `product.content_version`；任一变化都需要新方案快照；
- 方案快照引用本次产品快照，并冻结完整继承字段及预算结果；
- 接口返回类型化 `SnapshotRef`，消费者不保存快照载荷副本。

## 12. 事务与并发

- 商品聚合、内置方案、预算结果、文件关系和审计原子提交；
- 编辑商品时按商品根→从属工序→方案→预算结果的顺序锁定；
- 同一商品并发编辑使用 `row_version` 拒绝后提交者；
- 快照使用唯一键防止并发重复创建；冲突后读取已创建快照返回；
- 自定义方案与商品并发修改时，方案提交必须重新校验商品 `content_version`，避免基于过时继承值提交。

## 13. 权限、审计与错误

权限：`product.create`、`product.update`、`product.deactivate`、`product.read`、`product.scheme.manage`、`product.snapshot.read`。

错误码：`PRODUCT_NOT_FOUND`、`PRODUCT_INACTIVE`、`PRODUCT_FIELD_INVALID`、`PRODUCT_TARGET_PROCESS_INVALID`、`PRODUCT_SCHEME_SYSTEM_MANAGED`、`PRODUCT_SCHEME_INVALID`、`PRODUCT_BUDGET_CALCULATION_FAILED`、`PRODUCT_VERSION_CONFLICT`、`PRODUCT_SNAPSHOT_CONFLICT`。

审计必须能显示商品或方案修改前后版本、操作者、原因和受影响预算结果。

## 14. 页面与交互要求

- 商品列表：编号、名称、状态、标准售价、标准目标工序、当前预算和更新时间；
- 新建/编辑商品：按“基本信息→制作→捏毛装袋→缝边剪袋→额外费用→预算预览”分区；
- 页面选择星级时带出分钟，提交后显示为商品保存值；
- 自定义方案在商品编辑/详情中管理，不在新建商品时强制填写；
- 方案页面将继承只读字段明确标识，不提供编辑控件；
- 内置标准方案标识为“系统方案”，不显示设为默认、编辑或删除按钮；
- 来源选择只有“工作室提供/客户提供”；
- 目标工序变化时只展示目标范围内的工序字段。

## 15. 验收标准

- 商品创建一次形成完整商品、内置标准方案和预算结果；任一步失败无残留；
- 修改星级静态数据不改变既有商品分钟；
- 商品编辑自动同步内置方案且不能独立编辑内置方案；
- 内置方案和自定义方案使用同一套完整方案表和 DTO；
- 自定义方案只能修改允许字段，克重、人工、标准分钟和额外费用始终由商品同步且只读；
- 目标工序正确控制成本范围；
- 客户供料保留全资源价值但不进入工作室承担成本；
- 模具数量和每日批次参与单日最大产能；
- 快照按内容版本复用，商品继承字段变化会使方案产生新快照；
- 历史订单仍能解析旧商品/方案快照；
- 关联商品的其他任务能冻结商品快照和其他任务单件人工费，后续商品修改不回溯；
- 商品模块不访问基础资料、订单或排班表。

## 16. 明确不采用

不采用旧方案中的通用材料表、动态材料预算行、装箱工序、方案默认选择、方案可编辑人工工时/提成、商品保存后持续引用全局默认值、每次编辑无条件生成快照。

## 17. 待确认问题

本模块当前无阻塞一期开发的业务问题。

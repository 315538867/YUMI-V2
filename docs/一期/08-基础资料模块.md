# 基础资料模块

> 模块代码：`base-data`

## 1. 模块说明

基础资料模块管理客户、员工、就业与工种资格、全局有效工作时间标准、系统静态选项和商品录入默认值。商品和小组是独立模块，不属于基础资料。

## 2. 一期需求和范围

- 客户基本资料、联系方式和默认收货信息；
- 员工基本资料、入职、离职和返聘；
- 员工当前工种资格及历史变化；
- 制作星级和对应标准制作分钟；
- 捏毛装袋、缝边剪袋等录入所需的标准时间选项；
- 全局每日有效工作分钟标准，供个人和小组任务评估使用；
- 商品录入默认值：胶水损耗率、胶水单价、色浆单价等；
- 为订单、商品、排班和工资提供公开查询或快照。

一期不管理商品、生产小组、材料目录、库存、工资规则和账号权限。

## 3. 模块功能与模块边界

### 3.1 模块功能

- 创建、修改、停用客户；
- 取得客户当前资料和客户快照；
- 创建员工，办理离职和返聘；
- 授予或撤销工种资格；
- 维护允许用户配置的静态数据条目；
- 维护商品录入默认值；
- 维护全局每日有效工作分钟标准并取得当前标准快照；
- 查询在职和工种资格；
- 取得员工排班主体当前快照。

### 3.2 模块拥有

客户、员工、工种资格、静态选项、商品录入默认值、全局每日有效工作分钟标准，以及客户、员工和有效工作时间标准快照。

### 3.3 模块不拥有

商品、小组、排班任务、生产事实、工资规则、账号权限、材料目录和库存。下游只能通过公开查询或快照取得能力，本模块也不访问下游业务表。

## 4. 业务规则

1. 客户编号和员工编号创建后不可修改、不可复用。
2. 客户修改不回溯订单中已冻结的客户和收货信息。
3. 员工返聘沿用原员工身份，不创建同一人的第二身份。
4. 离职不删除历史生产、排班和工资记录。
5. 排班资格同时要求员工在职且具有目标工种资格。
6. 静态数据被选择时，业务模块应把需要的值复制到自己的当前记录；后续不动态引用静态值。
7. 商品录入默认值只用于页面预填；商品提交后最终值由商品模块保存。
8. 修改录入默认值不刷新既有商品，也不生成业务快照。
9. 一期只维护一套全局每日有效工作分钟标准，不按员工或小组分别配置；个人和小组都比较同一个“任务经过时间”上限，小组人数不会把有效分钟相乘。
10. 有效工作时间标准变化只影响新建或正式重新评估的任务；历史评估使用当时保存的标准快照引用和值。
11. 有效工作时间只是计算输入，排班必须通过本模块接口取得，不能自行配置或复制默认值。
12. 本模块不提供服务端草稿。

## 5. 状态设计

- 客户：`ACTIVE / INACTIVE`；
- 员工：`EMPLOYED / DEPARTED`；
- 工种资格：当前投影 `ACTIVE / REVOKED`，历史由事实表达；
- 静态条目：`ACTIVE / INACTIVE`；
- 有效工作时间标准：当前记录固定为一套活动配置；历史版本通过快照保留。

## 8. 事务、并发和快照

- 客户或员工当前记录、变化事实、内容版本和审计同事务提交；
- 工种资格授予/撤销使用唯一当前关系和行锁防重；
- 客户/员工快照按 `content_version` 创建或复用；
- 有效工作时间标准修改时同时递增 `content_version`，正式任务按内容版本创建或复用标准快照；
- 静态条目和默认值更新使用 `row_version`；
- 页面显示的资格结果不能代替排班正式命令内的再次校验。

## 9. 权限、页面和错误

权限：`base.customer.manage`、`base.customer.read`、`base.employee.manage`、`base.employee.read`、`base.static.manage`、`base.static.read`、`base.defaults.manage`、`base.defaults.read`、`base.work-time.manage`、`base.work-time.read`。

页面：客户列表/详情、员工列表/详情、就业和资格历史、静态数据维护、商品录入默认值、有效工作时间标准配置。

错误码：`CUSTOMER_NOT_FOUND`、`CUSTOMER_INACTIVE`、`EMPLOYEE_NOT_EMPLOYED`、`EMPLOYEE_WORK_TYPE_MISSING`、`EMPLOYMENT_TRANSITION_INVALID`、`STATIC_ENTRY_IN_USE`、`WORK_TIME_STANDARD_INVALID`、`WORK_TIME_STANDARD_UNAVAILABLE`、`BASE_DATA_VERSION_CONFLICT`。

## 10. 验收标准

- 客户修改后新订单取得新快照，历史订单仍解析旧快照；
- 员工离职后不能承接新任务，但历史任务和工资仍可展示；
- 重复授予资格不会产生两个当前资格；
- 修改制作星级标准分钟不会修改已保存商品的制作分钟；
- 修改商品录入默认值只影响后续页面预填，不影响既有商品；
- 个人和小组排班都通过接口取得同一全局每日有效工作分钟标准；
- 修改有效工作时间后，新任务使用新标准，历史评估仍能解析旧标准快照；
- 快照同一内容版本重复取得返回同一引用。

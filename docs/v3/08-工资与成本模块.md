# V3 工资与成本模块

> 模块代码：`payroll`（工资）、`cost`（成本）  
> 文档版本：V3.0  
> 编写日期：2026-10-30  
> 状态：V3 工资与成本模块评审稿；评审通过前不进入页面实现

本文是 V3 工资与成本模块的唯一需求与设计依据。工资子域负责工资期间、参考、逐人核定、调整和发放；成本子域按订单商品的实际生产数量计算实际产量口径成本。两者都不做考勤、现金账户、经营费用、库存和会计总账。

## 摘要

- 工资按自然周（周一至周日）建期间；一个期间可以有多次参考运行，已核定员工不因新参考被覆盖。
- 无责任胶水额度仍按自然月计算；周工资按周累计占用当月额度，每周只扣本周新增超出部分。
- 计时工资 = 考勤出勤分钟 ÷ 60 × 岗位时薪。
- 制作岗位按日考核：每个工作日制作计时工资分钟 = min（当日制作出勤分钟，当日制作任务标准分钟）；其他岗位按当日出勤分钟。
- 制作任务标准分钟 = 制作生产记录完成数量 × 制作标准分钟；完成数量含合格、返工（返修）和报废，因为报废和返修都占用了制作时间。
- 工序提成按“同一订单商品 × 同一工序 × 同一员工”只算一次：只汇总合格数量 × 工序提成；返工数量、报废和未完成不计；返工后合格的，按返工记录的合格数量计入。
- 其他岗位只有计时工资，没有工序提成。
- 胶水扣款只作用于制作岗位：报废核验时可以选择“计入责任”和责任制作员工；只有计入责任的报废才计算胶水。
- 每名制作员工每月有无责任胶水额度；责任报废胶水超过额度的部分，按商品冻结胶水单价自动扣减工资，主管可在最终核定中调整。
- 请假不计薪；本期加班按正常岗位时薪计，不加倍；未完成数量不计工资。
- 工资结果 = 计时工资 + 工序提成 − 胶水扣款，最低为 0；主管逐人核定最终金额，核定后可追加调整，再登记发放。
- 成本按“实际完成数量 × 商品/方案冻结预算成本（工作室承担部分）”计算；材料、人工、工序其他和额外单件成本分开展示。
- 成本是经营分析口径，不是法定财务账；成本人工使用商品冻结预算，不等于实发工资，实发工资差异不摊回订单。
- 成本在查询时实时计算，不建成本表；生产记录或快照变化后成本随之变化。
- 所有金额、成本、扣款和利润公式归计算中心；工资模块保存参考结果、核定、调整和发放事实。
- 工资 9 张表；成本 0 张表。

## 1. 模块说明

工资与成本模块回答两个问题：

- 某员工某月应发多少工资：出勤多少、哪些生产记录有提成、责任报废扣多少胶水、主管最终核定多少、已经发了多少；
- 某订单或商品实际生产花了多少成本：材料、工序人工、提成、工序其他和额外单件成本各多少，订单毛利多少。

工资和成本分开：
- 工资按员工和考勤/生产事实计算，允许主管核定和调整；
- 成本按订单商品的实际完成数量和商品/方案冻结预算计算，用于经营分析，不把实发工资差异摊回订单。

考勤模块提供工时，生产模块提供完成数量、报废责任和商品/方案快照引用，商品模块提供冻结的工序提成、材料成本和预算成本，全局模块提供岗位时薪和每月无责任胶水量。工资与成本模块只保存自己的期间、参考、核定、调整和发放事实。

## 2. 用户与使用场景

### 2.1 用户

| 用户 | 关心什么 | 在工资与成本模块做什么 |
|---|---|---|
| 管理员 | 本周每人计时多少、提成多少、扣了多少胶水、最终发多少 | 建工资期间、运行参考、逐人核定、调整、登记发放 |
| 老板 | 工资总额、订单成本和毛利 | 查看工资汇总、订单成本、商品毛利 |
| 生产负责人 | 制作任务标准分钟是否低于出勤、报废是否计入责任 | 在生产核验时选择是否计入责任和责任制作员工 |
| 财务 | 员工应付、已付、未付 | 登记工资发放，查看调整和发放记录 |
| 报表 | 工资、成本和毛利汇总 | 通过公开查询或后续报表投影读取 |

### 2.2 现状与目标

管理员现在用 Excel 按月汇总兼职员工的出勤、生产提成、报废扣款和最终工资；成本按商品预算或估算看。

V3 把工资和成本拆成两条清晰口径：

- 考勤决定计时工资，生产决定提成和胶水扣款；
- 制作岗位按任务标准分钟考核，打卡多但任务少时只按任务分钟计；
- 报废不计提成，责任报废按制作员工月度无责任胶水额度扣胶水；
- 工资逐人核定，核定后新参考不覆盖，调整和发放留痕；
- 成本按实际生产数量和冻结预算计算，不混入实发工资差异；
- 订单毛利可以直接从成本和应收金额得到。

### 3.1 本期提供

- 工资期间创建和查询；
- 工资参考运行和参考行；
- 计时工资参考（考勤分钟 × 岗位时薪）；
- 制作岗位任务标准分钟考核和计时上限；
- 工序提成参考（合格数量 × 工序提成）；

- 员工工资结果、逐人核定、调整和发放；
- 岗位时薪和无责任胶水量的版本引用；
- 订单商品实际产量成本查询；
- 订单成本、商品成本和订单毛利查询；
- 工资与成本权限、审计和幂等。

- 考勤登记和打卡（由考勤模块负责）；

- 计时工资的加班倍率、节假日倍率和夜班补贴；
- 病假、事假带薪规则和年假余额；
- 社保、个税、公积金和银行代发文件；
- 现金账户、银行账户、资金流水和对账；
- 经营费用、房租水电实际支出和会计总账；
- 库存、采购、材料批次和实际采购价；
- 工资预算、人工成本分摊到部门或商品；
- 把实发工资差异分摊回订单成本；
- 工资条、工资单文件和邮件发送；
- 员工自助查询工资；
- 动态工资公式、公式脚本和公式编辑器。

## 4. 业务概念

| 术语 | 定义 |
|---|---|
| 工资期间 | 一个自然周（周一至周日）的工资计算范围，例如 `2026-10-26_2026-11-01` |
| 工资运行 | 某期间的一次参考计算，保存本次参考行和来源指纹 |
| 计时工资 | 考勤出勤分钟按岗位时薪折算的工资 |
| 制作任务标准分钟 | 制作生产记录完成数量 × 制作标准分钟 |
| 制作计时上限 | 制作岗位每个工作日的计时工资分钟不超过当日制作任务标准分钟 |
| 工序提成 | 商品/方案冻结的每件提成，按同一商品、工序、员工的合格产出汇总后计一次 |
| 胶水责任报废 | 生产核验时标记“计入责任”的报废，可指定责任制作员工 |
| 无责任胶水额度 | 每名制作员工每月可免于扣款的胶水重量 |
| 胶水扣款 | 责任报废胶水超过月度额度后，按冻结胶水单价计算的扣款 |
| 工资参考 | 计时工资 + 工序提成 − 胶水扣款，运行生成，不是最终实发 |
| 核定 | 主管确认某员工最终工资金额，核定后不被新参考覆盖 |
| 调整 | 核定后追加的有符号金额调整，必须写原因 |
| 发放 | 对已核定工资登记的实际支付事实 |
| 实际产量成本 | 按实际完成数量和商品/方案冻结预算计算的订单商品成本 |

关系：

```text
考勤记录 N ── 1 计时工资参考行
生产记录 N ── 1 工序提成参考行
生产记录（责任报废）N ── 1 胶水扣款参考行
工资期间 1 ── N 工资运行
工资期间 1 ── N 员工工资结果
员工工资结果 1 ── 1 核定
员工工资结果 1 ── N 调整
员工工资结果 1 ── N 发放
订单商品 1 ── 1 实际产量成本（查询时计算，不落成本表）
```

| 字段 | 必填 | 类型/精度 | 规则 |

### 5.5 胶水扣款月度参考行

胶水额度按月，工资按周；每个工资运行、每名责任制作员工、每个自然月生成一条月度累计参考行，只把“本周新增超出部分”计入本周工资。

| 字段 | 必填 | 类型/精度 | 规则 |
|---|---|---|---|
| 参考行业务标识 | 系统 | `VARCHAR(64)` | 稳定标识 |
| 工资运行 | 系统 | `VARCHAR(64)` | 所属运行 |
| 责任员工 | 系统 | `VARCHAR(64)` | 生产记录选定的责任制作员工 |
| 责任员工快照引用 | 系统 | `VARCHAR(64)` + 版本 | 员工身份 |
| 自然月 | 系统 | `CHAR(7)` | `YYYY-MM`，按报废生产日期归月 |
| 月度无责任额度 | 系统 | `DECIMAL(19,4)` | 自然月第一天生效的额度（克） |
| 额度参数版本 | 系统 | `GlobalParameterVersionRef` | 参数代码、版本号和生效日期 |
| 截至本周累计报废胶水克数 | 系统 | `DECIMAL(19,4)` | 当月责任报废胶水克数，截至本周结束日 |
| 截至本周累计免扣克数 | 系统 | `DECIMAL(19,4)` | 不超过月度额度 |
| 截至本周累计超出克数 | 系统 | `DECIMAL(19,4)` | 累计报废胶水克数 − 累计免扣克数 |
| 截至本周累计超出成本 | 系统 | `DECIMAL(19,2)` | 按每条责任报废的冻结胶水单价计算后合计 |
| 之前周已扣金额 | 系统 | `DECIMAL(19,2)` | 同员工、同自然月、之前工资期间最近成功运行的胶水扣款合计 |
| 本周扣款金额 | 系统 | `DECIMAL(19,2)` | `max(0, 累计超出成本 − 之前周已扣金额)` |
| 公式/规则/舍入版本 | 系统 | `VARCHAR(32)` | 计算中心返回 |
| 输入指纹 | 系统 | `CHAR(64)` | 计算中心返回 |

同一运行、同一责任员工、同一自然月只有一条月度参考行。跨月周分别生成两个自然月的参考行。

## 6. 业务规则

### R1 工资期间

- 工资期间按自然周创建，开始日期必须是周一，结束日期为周日；
- 期间代码为 `YYYY-MM-DD_YYYY-MM-DD`，由开始和结束日期生成；
- 同一个开始日期只能有一个工资期间，周与周不能重叠；
- 期间可以跨月；跨月周内的日期按自然日期归入当周，胶水额度按日期所属自然月分别计算；
- 期间起止日期由系统生成，不接受客户端修改结束日期；
- 期间没有封账状态；是否完成由员工核定和发放状态派生；
- 期间可以重复运行参考，已核定员工不被新运行覆盖。

### R2 参考运行

- 运行读取期间内 `ACTIVE` 考勤记录和 `ACTIVE` 生产记录；
- 运行开始时记录来源截止时间；
- 胶水参考额外读取责任员工当月截至本周结束的责任报废和之前周已扣金额，用于月度累计；
- 运行成功生成计时、提成和胶水参考行，并写参考指纹；参考指纹包含考勤内容版本和生产记录/快照版本；
- 运行失败整体回滚，不留下部分参考行；
- 同一期间运行号递增，旧的成功运行标记 `SUPERSEDED`；
- 新运行只更新 `PENDING` 员工结果；`CONFIRMED` 结果保留原运行和原核定；
- 已有 `PENDING` 结果但本次运行没有参考行的，计时、提成、胶水扣款和参考工资置 0，保留结果等待核定或手工处理；
- 已核定员工可以在页面看到“参考已更新”的差异提示，但应付金额不变；
- 运行不生成应付、成本或发放。

### R3 计时工资

- 计时工资按员工、考勤岗位和工作日期逐日计算，再按期间汇总；计时参考行的员工快照取该日考勤记录的员工快照；
- 出勤分钟取考勤 `ACTIVE` 记录的 `workedMinutes` 合计；
- 岗位时薪取工资周期间开始日生效的全局岗位时薪版本；
- 周中调薪本周不生效，下一周开始使用新版本；工资不按天切换岗位时薪；
- 制作岗位：
  - 任务标准分钟 = 该员工当日制作生产记录完成数量 × 制作标准分钟合计；
  - 完成数量 = 合格 + 返工（返修） + 报废；
  - 计时工资分钟 = min(当日制作出勤分钟, 当日任务标准分钟)；
- 其他岗位：
  - 计时工资分钟 = 当日出勤分钟；
  - 任务标准分钟固定为 0；
- 计时工资金额 = `HALF_UP(计时工资分钟 ÷ 60 × 岗位时薪, 2)`；
- 请假分钟不计薪；加班分钟包含在出勤分钟中，本期按正常岗位时薪计，不加倍；
- 未完成数量不计入任务标准分钟；
- 返工/返修任务的生产记录按它自己的工序标准分钟计入对应员工当天的任务标准分钟；
- 岗位时薪缺失或小于等于 0 时运行失败，返回 `PAYROLL_HOURLY_RATE_MISSING`。

### R4 工序提成

- 提成按订单商品、工序和员工汇总，每个运行只生成一条提成参考行；
- 只汇总 `ACTIVE` 生产记录的合格数量；`NORMAL` 和 `REWORK` 记录都按合格数量计；
- 返工数量、报废数量和未完成数量不计提成；
- 返工后产出的合格数量在 `REWORK` 记录中计入，返工前的返工数量不再重复计；
- 单件提成取商品/方案快照中该工序的冻结提成；
- 提成金额 = `HALF_UP(提成数量 × 单件提成, 2)`；
- 制作、捏毛装袋、缝边剪袋都适用；
- 其他岗位没有生产记录，不产生提成；
- 同一订单商品、同一工序由多名员工完成时，按员工分别生成提成行，每名员工拿自己产出的合格数量；
- 商品/方案快照缺失或工序提成缺失时运行失败，返回 `PAYROLL_COMMISSION_BASIS_MISSING`。

### R5 胶水扣款

- 只有生产核验时标记“计入责任”的报废记录才进入胶水扣款；
- 责任员工必须是制作岗位员工；可以是当前记录员工，也可以由主管改选其他制作员工；
- 单件胶水用量取商品快照的含损耗胶水用量（克/件）；
- 报废胶水克数 = `HALF_UP(报废数量 × 单件胶水用量, 4)`；
- 每名责任制作员工每月有无责任胶水额度，额度取自然月第一天生效的全局参数；
- 胶水额度按月计算，工资按周运行；跨周不重置额度；
- 同一员工、同一自然月的责任报废按生产日期、生产记录标识升序分配额度；
- 截至本周结束日，累计报废胶水克数 = 当月全部责任报废胶水克数；累计免扣克数不超过月度额度；累计超出克数 = 累计报废胶水克数 − 累计免扣克数；
- 累计超出成本按每条责任报废的超出克数 × 该商品冻结胶水单价计算后合计；
- 本周扣款金额 = `max(0, 截至本周累计超出成本 − 之前周已扣金额)`；
- 之前周已扣金额取同员工、同自然月、之前工资期间最近成功运行的胶水扣款合计，不重复累计；之前周即使未确认也按其最近成功运行计入，后续重跑后本周需重跑；
- 之前工资期间重跑后，本周工资需要重新运行以更新之前周已扣金额；已核定周不被覆盖，差额由主管调整；
- 跨月周按日期所属自然月分别生成参考行，分别使用各自月份的额度；
- 胶水单价取商品快照冻结单价；不同商品可以不同；
- 额度未用完不结转、不共享；
- 责任报废被作废导致累计超出成本下降时，本周扣款金额取 0，不自动退款；差额由主管调整；
- 额度参数缺失时运行失败，返回 `PAYROLL_GLUE_ALLOWANCE_MISSING`；
- 商品胶水用量或单价缺失时运行失败，返回 `PAYROLL_GLUE_BASIS_MISSING`；
- 未标记责任或未选择责任制作员工的报废不扣胶水。

示例（额度 100 克）：

```text
第 1 周责任报废胶水 60 克 → 累计 60 克，未超额度，本周扣 0
第 2 周再报废 80 克 → 累计 140 克，超出 40 克，本周扣 40 克 × 单价
第 3 周再报废 20 克 → 累计 160 克，超出 60 克，本周再扣 20 克 × 单价
```

每周只扣“本周新增超出部分”，不是每周重新给 100 克，也不是月末一次性重算。

### R6 工资参考与核定

- 员工参考工资 = `max(0, 计时工资 + 工序提成 − 胶水扣款)`；
- 胶水扣款超过计时和提成时，参考工资为 0，超出部分不结转、不形成员工欠款；
- 主管逐人核定实际工资金额，核定金额不小于 0，核定说明必填；
- 核定必须携带当前参考运行和参考指纹；参考已更新时返回 `PAYROLL_REFERENCE_CHANGED`，要求刷新后再核定；手工结果没有参考运行时忽略参考运行和指纹；
- 核定后结果状态为 `CONFIRMED`，新参考运行不覆盖核定金额；
- 核对金额可以与参考不同，系统不要求差额原因，但核定说明必填；
- 零金额可以核定；零金额结果发放状态视为 `PAID`，页面显示“无需发放”。

### R7 调整

- 只有已核定结果可以调整；
- 调整金额为有符号金额，不能为 0，精确到分；
- 调整原因必填，业务日期不得晚于当天；
- 调整后应付金额 = 核定金额 + 有效调整合计；
- 应付金额不得小于 0，也不得小于已付金额；不满足时返回 `PAYROLL_ADJUSTMENT_BELOW_PAID`；
- 调整只追加，不修改、不删除；录错用相反金额和原因冲回；
- 调整不改核定金额、参考行和发放记录。

### R8 发放

- 只有已核定结果可以发放；
- 发放金额大于 0，不超过未付金额；
- 发放日期不得晚于当天；
- 发放方式只使用 `CASH / BANK / OTHER`；
- 发放后更新已付金额、未付金额和发放状态；
- 发放记录可以作废；作废必须写原因，作废后重新计算已付和未付；
- 已付金额不能超过应付金额；
- 工资发放只登记工资事实，不建现金账户、不做银行对账。

### R9 员工结果

- 同一期间、同一员工只有一条工资结果；
- 运行只为有参考行的员工创建或更新结果；
- 没有考勤和生产记录的员工，管理员可以创建手工结果，参考金额为 0，再核定实际金额；
- 手工结果不因参考运行被删除或覆盖；
- 结果保存员工快照引用；参考结果取该员工本周最近一条计时、提成或胶水参考行的员工快照，手工结果取当前员工快照；员工改名、调岗或离职不改变已核定结果；
- 未核定结果不能发放；
- 结果行版本用于核定、调整和发放的并发控制。

### R10 成本

- 成本按订单商品查询时实时计算，不建成本表；
- 只使用 `ACTIVE` 生产记录；
- 完成数量 = 合格 + 返工 + 报废；
- 材料、工序其他和额外单件成本取商品/方案快照的预算成本行；
- 人工和提成取商品/方案快照的预算人工和提成，不使用实发工资；
- 材料、工序其他只按 `NORMAL` 生产记录计算，避免返工重复计材料；返工新增用料本期不单独建模，不补计材料；
- 人工和提成按 `NORMAL` 和 `REWORK` 记录计算；
- 额外单件成本按目标工序 `NORMAL` 记录的完成数量计算一次，返工不重复计；其中其他任务人工费计入人工成本，其余额外费用计入额外单件成本；
- 只计入 `bearerType = STUDIO` 的成本；
- 客户供料价值单独展示，不计入工作室成本；
- 成本金额 4 位小数；
- 成本随生产记录作废、重录和快照变化而变化，不是不可变财务事实；
- 成本不使用工资核定、调整和发放数据。

### R11 订单毛利

- 订单商品毛利 = 订单商品明细金额 − 订单商品成本；
- 订单毛利 = 订单应收金额 − 订单成本合计；
- 毛利率 = `HALF_UP(毛利 ÷ 应收金额, 8)`，应收为 0 时为空；
- 明细毛利之和不要求等于订单毛利，因为订单有整单优惠；
- 毛利只用于经营分析，不生成会计凭证或应收应付。

### R12 与考勤、生产边界

- 考勤模块拥有出勤分钟、请假、加班和岗位代码；
- 生产模块拥有完成数量、报废数量和责任报废选择；
- 工资模块只读取考勤和生产公开查询，不直接读考勤表或生产表；
- 工资模块不修改考勤和生产；
- 考勤或生产记录更正后，新参考运行使用新事实；已核定结果不自动变化。

### R13 与商品、全局边界

- 商品模块提供工序标准分钟、提成、胶水用量、胶水单价和预算成本行；
- 全局模块提供岗位时薪和每月无责任胶水量；
- 工资模块保存参数版本引用，不复制参数当前值；
- 商品或全局参数修改不回溯已核定工资和已有成本查询结果（成本查询按当前快照引用计算）；
- 工资模块不维护商品、岗位和全局参数。

### R14 权限、审计与查询范围

- 工资和成本查询按权限控制；
- 参考运行、核定、调整、发放和发放作废都写平台审计；
- 工资期间、参考行、核定、调整和发放不能物理删除；
- 参考查询日期范围不超过 366 天；
- 成本列表单页不超过 50 单；
- 工资结果和成本查询不返回内部行版本和指纹给普通页面，只在并发操作和诊断中使用。

## 7. 状态设计

### 7.1 工资运行

| 当前状态 | 操作 | 目标状态 | 说明 |
|---|---|---|---|
| `RUNNING` | 成功 | `SUCCEEDED` | 保存参考行和指纹 |
| `RUNNING` | 失败 | `FAILED` | 整体回滚，不保留部分参考 |
| `SUCCEEDED` | 新运行成功 | `SUPERSEDED` | 只影响未核定结果 |
| `FAILED` | 重新运行 | 新运行 | 失败运行保留 |

### 7.2 员工结果

| 当前状态 | 操作 | 目标状态 | 说明 |
|---|---|---|---|
| `PENDING` | 核定 | `CONFIRMED` | 写核定事实和应付 |
| `CONFIRMED` | 调整 | `CONFIRMED` | 追加调整，应付变化 |
| `CONFIRMED` | 发放 | `CONFIRMED` | 发放状态独立变化 |
| `CONFIRMED` | 重新核定 | 不允许 | 只能调整 |

发放状态由应付和已付派生：

```text
应付 = 0                         → PAID（无需发放）
已付 = 0 且 应付 > 0             → UNPAID
0 < 已付 < 应付                  → PARTIAL
已付 ≥ 应付                      → PAID
```

## 10. 事务与并发

### 10.1 创建工资期间

```text
校验开始日期为周一且结束日期为开始日期后 6 天
→ 检查同月唯一
→ 写期间
→ 写审计
→ 一次提交
```

### 10.2 参考运行

```text
锁定工资期间行
→ 检查没有 RUNNING 运行
→ 读取期间内 ACTIVE 考勤和生产记录
→ 读取岗位时薪和无责任胶水额度版本
→ 读取商品/方案快照，计算计时、提成和胶水参考
→ 写运行和参考行
→ 对每个有参考行或已有 PENDING 结果的员工创建或更新 PENDING 结果
→ 旧的成功运行标记 SUPERSEDED
→ 写审计
→ 一次提交
```

- 运行失败整体回滚，运行标记失败用独立事务；
- 已核定结果不更新参考运行、参考金额和应付；
- 参考指纹由参考行稳定排序生成；
- 并发运行由期间行版本和 RUNNING 状态串行化。

### 10.3 核定

```text
锁定工资结果行
→ 校验 PENDING 和行版本
→ 校验参考运行和指纹是当前最新
→ 写核定事实
→ 更新结果核定金额、应付、状态和行版本
→ 写审计
→ 一次提交
```

### 10.4 调整

```text
锁定工资结果行
→ 校验 CONFIRMED 和行版本
→ 校验调整金额、原因、业务日期
→ 计算新应付，校验不小于 0 且不小于已付
→ 写调整事实
→ 更新调整金额、应付、未付和行版本
→ 写审计
→ 一次提交
```

### 10.5 发放与作废

```text
锁定工资结果行
→ 校验 CONFIRMED
→ 校验金额、日期和未付
→ 写发放事实
→ 更新已付、未付和发放状态
→ 写审计
→ 一次提交
```

作废发放反向计算已付和未付，不能作废其他员工的发放。

### 10.6 并发与幂等

- 工资期间、结果和发放使用 `row_version`；
- 参考运行、核定、调整和发放使用平台幂等键；
- 同一结果并发核定只有一方成功；
- 同一结果并发发放允许串行追加，超付由未付金额校验拒绝；
- 死锁只允许重试整个幂等命令。

## 11. 历史与追溯

### 11.1 参考与核定

- 每次参考运行保留运行号和参考行；
- 已核定结果保留核定时的运行引用、指纹和金额；
- 新运行不覆盖已核定结果，只更新未核定结果；
- 参考行只追加，不修改、不删除；
- 运行失败不留下部分参考行。

### 11.2 调整与发放

- 核定只写一次，不能重新核定；
- 调整只追加，不修改、不删除；错误用相反金额冲回；
- 发放记录保留；错误发放作废，不物理删除；
- 已付金额始终由有效发放汇总，不由页面直接改。

### 11.3 成本

- 成本是查询时投影，不是不可变事实；
- 生产记录作废或重录后，成本按当前有效记录重新计算；
- 成本查询结果可以展示计算时间、公式版本和输入指纹，供追溯；
- 成本不保存历史版本；需要历史成本时由报表另行快照，不在本模块建表。

## 12. 权限、审计与错误

### 12.1 权限

| 权限 | 能力 |
|---|---|
| `payroll.read` | 查看工资期间、运行、结果、参考行和发放 |
| `payroll.run` | 运行工资参考 |
| `payroll.confirm` | 核定员工工资 |
| `payroll.adjust` | 追加工资调整 |
| `payroll.pay` | 登记工资发放 |
| `payroll.payment.void` | 作废工资发放 |
| `cost.read` | 查看订单商品成本和毛利 |

角色建议：

- 管理员：全部工资和成本权限；
- 老板：`payroll.read`、`cost.read`；
- 生产负责人：`payroll.run`、`payroll.read`；
- 财务：`payroll.confirm`、`payroll.adjust`、`payroll.pay`、`payroll.payment.void`、`payroll.read`；
- 工资操作员：`payroll.read`、`payroll.run`，不授予发放权限；
- 报表：`payroll.read`、`cost.read` 的只读查询，不直接读表。

### 12.2 审计

必须审计：

- 工资期间创建；
- 工资参考运行成功和失败；
- 员工核定；
- 工资调整；
- 工资发放和发放作废；
- 成本查询不写审计，成本不改变业务数据。

## 13. 页面与交互要求

### 13.1 页面清单

| 页面 | 建议路由 | 目的 |
|---|---|---|
| 工资期间 | `/payroll` | 周期间列表、进度和总额 |
| 工资期间详情 | `/payroll/:periodId` | 员工工资列表、运行、核定、调整、发放 |
| 员工工资详情 | `/payroll/:periodId/employees/:employeeId` | 计时、提成、胶水明细和操作 |
| 订单成本 | `/costs` | 订单成本和毛利列表 |
| 订单成本详情 | `/costs/:orderId` | 订单商品成本明细 |

成本也可以嵌入订单详情页，但必须有独立入口和权限。

### 13.2 工资期间

- 紧凑页栏：周一日期、周范围、运行按钮、进度、工资总额；
- 列：员工、岗位、计时工资、工序提成、胶水扣款、参考工资、核定金额、已付、未付、状态；
- 顶部汇总：参考合计、核定合计、已付合计、未付合计；
- 参考行数与考勤、生产来源数量可展开查看；
- 已核定行显示“参考已更新”提示，但金额不自动变；
- 未核定行可以打开详情核定；
- 发放通过详情页的发放对话框，不单独建页面；
- 不显示英文枚举和内部版本号。

### 13.3 员工工资详情

按“先结论、后明细”组织：

1. 页头：员工、岗位、期间、状态；
2. 汇总：计时工资、工序提成、胶水扣款、参考工资、核定金额、调整、应付、已付、未付；
3. 计时明细：日期、岗位、出勤分钟、任务标准分钟、计时分钟、岗位时薪、金额；
4. 提成明细：订单、商品、工序、生产日期范围、来源记录数、合格提成数量、单件提成、金额；
5. 胶水明细：自然月、月度额度、截至本周累计报废胶水克数、累计免扣、累计超出、累计超出成本、之前周已扣、本周扣款；可展开查看责任报废记录；
6. 核定、调整和发放历史。

操作：

- 未核定：核定按钮，填写核定金额和说明；
- 已核定：调整按钮、发放按钮、发放作废按钮；
- 参考已更新：提示刷新运行后再核定；
- 任何操作都带行版本，冲突提示刷新；
- 不提供删除核定、调整或发放。

### 13.4 订单成本

- 列表列：订单号、客户、应收、成本、毛利、毛利率、状态；
- 筛选：订单日期、状态、客户/商品关键字；
- 详情按订单商品分组，显示材料、人工、提成、工序其他、额外成本；
- 客户供料价值单独显示，不计入工作室成本；
- 成本依据缺失的行显示“依据缺失”，不填 0；
- 成本金额 4 位小数，毛利 2 位，毛利率 2 位百分比；
- 不显示内部指纹和行版本。

### 13.5 全局交互原则

- 页面使用 V3 全站设计语言和现有组件；
- 字段校验内联显示，接口错误统一提示；
- 时间显示本地日期，不显示微秒时间戳；
- 金额显示人民币，工资 2 位小数，成本 4 位小数；
- 不出现英文枚举原文；
- 未保存关闭前提示；
- 页面不提供工资条导出、银行文件和会计凭证。

## 14. 验收标准

### 14.1 工资期间与运行

- [ ] 同一个周一只能创建一个工资期间，开始日期必须是周一；
- [ ] 客户端只提交周一日期，结束日期和期间代码由系统生成；
- [ ] 参考运行读取期间内 `ACTIVE` 考勤和生产记录；
- [ ] 胶水参考额外读取同员工当月截至本周的责任报废和之前周已扣金额；
- [ ] 运行失败整体回滚，不留下部分参考行；
- [ ] 同一期间重复运行时旧运行标记 `SUPERSEDED`；
- [ ] 新运行只更新未核定结果，不覆盖已核定结果；
- [ ] 运行不生成应付、成本或发放。

### 14.2 计时工资

- [ ] 计时工资按员工、岗位和工作日期逐日计算，再按期间汇总；
- [ ] 制作岗位每个工作日计时工资分钟取“当日出勤分钟”和“当日任务标准分钟”的较小值；
- [ ] 制作任务标准分钟含合格、返工/返修和报废；
- [ ] 返工/返修任务的生产记录按自身工序标准分钟计入当日任务标准分钟；
- [ ] 其他岗位按出勤分钟，不参与制作上限；
- [ ] 岗位时薪按工资周期间开始日生效版本读取；
- [ ] 周中修改岗位时薪不改变本周工资，下一周才使用新版本；
- [ ] 岗位时薪缺失时运行失败，不使用默认值；
- [ ] 请假不计薪，加班按正常时薪计，不加倍；
- [ ] 计时工资金额按分钟和时薪计算，保留 2 位。

### 14.3 工序提成与胶水

- [ ] 提成按订单商品、工序、员工汇总，每个运行只生成一条行；
- [ ] 提成只汇总合格数量，NORMAL 和 REWORK 记录都按合格数量计；
- [ ] 返工数量、报废和未完成不计提成；返工后合格的按 REWORK 记录合格数量计；
- [ ] 制作、捏毛装袋、缝边剪袋都适用工序提成；
- [ ] 其他岗位没有提成；
- [ ] 只有勾选“计入责任”的报废才计算胶水；
- [ ] 责任员工必须是制作岗位，可改选；
- [ ] 报废胶水克数按商品冻结胶水用量计算；
- [ ] 每名制作员工每月额度独立，按生产日期顺序占用；
- [ ] 周工资按当月累计占用额度，跨周不重置；
- [ ] 本周扣款等于截至本周累计超出成本减去之前周已扣金额；
- [ ] 跨月周按自然月分别生成胶水参考行；
- [ ] 超出额度部分按冻结胶水单价扣款；
- [ ] 未用完额度不结转、不共享；
- [ ] 胶水扣款不超过计时和提成合计时，参考工资最低为 0；
- [ ] 胶水额度或商品胶水依据缺失时运行失败。

### 14.4 核定、调整与发放

- [ ] 未核定结果不能调整或发放；
- [ ] 核定金额不小于 0，核定说明必填；
- [ ] 参考运行或指纹变化后核定被拒绝；
- [ ] 已核定结果不被新参考覆盖；
- [ ] 调整金额有符号、非 0、原因必填；
- [ ] 调整后应付不小于 0 且不小于已付；
- [ ] 发放金额大于 0 且不超过未付；
- [ ] 发放日期不晚于当天；
- [ ] 发放作废必须写原因，作废后未付恢复；
- [ ] 核定、调整和发放不能物理删除。

### 14.5 成本与毛利

- [ ] 成本只使用 `ACTIVE` 生产记录；
- [ ] 材料、工序其他按 `NORMAL` 记录计算；
- [ ] 人工和提成按 `NORMAL` 和 `REWORK` 记录计算；
- [ ] 额外单件成本按目标工序 `NORMAL` 完成数量计算一次；
- [ ] 只计入工作室承担成本；
- [ ] 客户供料价值单独展示，不计入工作室成本；
- [ ] 成本金额 4 位小数，毛利 2 位，毛利率 8 位；
- [ ] 订单毛利 = 应收 − 订单成本；
- [ ] 明细毛利之和不强制等于订单毛利；
- [ ] 成本查询不建成本表，不修改生产、工资和订单；
- [ ] 成本列表按订单页批量取生产来源、方案快照和计算，不逐订单回查；
- [ ] 成本列表单页超过 50 单时返回范围错误。

### 14.6 权限、审计与边界

- [ ] 工资查询、运行、核定、调整、发放分别按权限控制；
- [ ] 所有工资写操作写平台审计；
- [ ] 工资不直接读考勤、生产、员工、商品、订单或全局表；
- [ ] 工资不计算考勤分钟，只读取考勤结果；
- [ ] 工资不修改生产记录和报废责任；
- [ ] 成本不使用工资核定、调整和发放数据；
- [ ] 不建现金账户、经营费用和会计总账；
- [ ] 字段错误内联显示，不出现英文原文和内部标识。

## 15. 明确不采用

- 不做考勤登记和打卡；
- 不做生产记录和报废责任选择；
- 不做加班倍率、节假日倍率、夜班补贴和调休；
- 不做病假、事假带薪规则和年假余额；
- 不做社保、个税、公积金和银行代发；
- 不做现金账户、银行账户和资金对账；
- 不做经营费用、房租水电实际支出和会计总账；
- 不做库存、采购、材料批次和实际采购价；
- 不做工资预算和人工成本部门分摊；
- 不把实发工资差异分摊回订单成本；
- 不做工资条、工资单文件和邮件发送；
- 不做员工自助工资查询；
- 不做动态工资公式和公式编辑器；
- 不做成本历史快照表和成本不可变事实表。

## 16. 与 V2 的主要差异

| V2 财务结算 | V3 工资与成本 |
|---|---|
| 工资期间按月或自定义，逐人核定 | 工资按自然周结算；无责任胶水额度仍按月累计，周工资只扣本周新增超出 |
| 工资参考以商品快照单件人工为主，逐人手工核定 | 计时按考勤岗位时薪，制作岗位有任务标准分钟上限；提成按合格+返工 |
| 报废责任和胶水减免是复杂参考，不自动扣 | 报废在核验时选择是否计入责任；制作员工月度无责任胶水额度，超出自动扣，主管可调整 |
| 工资、成本、现金在同一财务模块 | 工资与成本独立成模块；不做现金账户和经营费用 |
| 成本台账保存不可变成本事实 | 成本按订单商品实时计算，不建成本表 |
| 成本人工使用实际核定工资 | 成本人工使用商品冻结预算，实发差异不摊回订单 |
| 小组和效率因子参与工资 | V3 不做小组，固定岗位直接计薪 |

## 17. 外部依赖

### 17.1 平台能力

- 权限：`payroll.read`、`payroll.run`、`payroll.confirm`、`payroll.adjust`、`payroll.pay`、`payroll.payment.void`、`cost.read`；
- 审计：工资期间、运行、核定、调整、发放和发放作废；
- 幂等：所有工资写命令；
- 工资和成本不需要平台编号，业务标识由模块生成；
- 工资和成本不直接写平台审计表；
- 工资/成本内部调用考勤、生产、商品和订单查询时，按 `payroll.read` / `cost.read` 调用方权限鉴权，业务用户不需要对应模块的维护权限；商品预算只读权限只授予工资/成本服务角色。

### 17.2 考勤模块

- 通过 `AttendanceQuery.listPeriodRecords` 和 `summarizePeriod` 读取逐日出勤、岗位、请假和加班；
- 工资使用出勤分钟和岗位代码，不使用页面小时数；
- 工资按岗位代码和工资周期间开始日读取岗位时薪；
- 工资参考运行指纹包含考勤内容版本；考勤变化后需要重新运行；
- 工资不修改考勤；
- 工资不直接读 `attendance_records`。

### 17.3 生产模块

- 通过 `ProductionWageCostSourceQuery.listWageCostSources` 读取生产记录数量、报废责任和商品/方案快照引用；
- 工资使用合格、返工和报废数量；未完成数量只用于生产展示，不进入工资；
- 工资使用责任报废的责任员工；
- 工资明细展开责任报废记录时，按责任员工和自然月调用同一查询；
- 成本使用生产记录的工序和完成数量；
- 工资和成本不修改生产记录，不直接读生产表。

### 17.4 商品模块

- 通过商品/方案快照读取工序标准分钟、工序提成、胶水用量和胶水单价；
- 通过 `resolveSchemeSnapshots` 一次解析本页涉及的方案；
- 通过方案快照预算行读取材料、人工、工序其他和额外单件成本；
- 商品快照成本字段需要 `product.budget.read` 服务权限；
- 工资和成本不直接读商品表或快照表；
- 商品或方案修改不影响已核定工资；成本按快照引用计算。

### 17.5 全局模块

- 通过 `GlobalParameterQuery.at` 读取四个岗位时薪；
- 通过 `GlobalParameterQuery.at("MAKING_MONTHLY_GLUE_ALLOWANCE_GRAMS", 自然月第一天)` 读取制作员工月度无责任胶水量；
- 工资保存 `GlobalParameterVersionRef`；
- 工资和成本不维护全局参数，不直接读全局表。

### 17.6 订单模块

- 通过订单公开查询读取订单号、客户、明细金额和应收金额；
- 成本按订单商品明细计算，不修改订单；
- 订单毛利使用订单应收金额；
- 工资和成本不直接读订单表。

### 17.7 计算中心

- 计时工资、工序提成、胶水扣款、工资结果、成本行和订单毛利都调用计算中心公式；
- 工资模块保存参考行、核定、调整和发放事实；
- 成本查询实时调用计算中心，不保存成本结果；
- 计算中心不读工资、考勤、生产、商品、订单或全局表。

## 18. 已确认口径

1. 工资按自然周（周一至周日）建期间，参考运行和逐人核定分开；已核定结果不被新参考覆盖。
2. 计时工资 = 考勤出勤分钟 ÷ 60 × 岗位时薪；岗位时薪取工资周期间开始日生效版本。
3. 制作岗位每个工作日计时工资分钟取 min（当日制作出勤分钟，当日制作任务标准分钟）；其他岗位按当日出勤分钟。
4. 制作任务标准分钟按日计算 = 当日完成数量 × 制作标准分钟；完成数量含合格、返工（返修）和报废。
5. 工序提成按同一订单商品、同一工序、同一员工只算一次；只汇总合格数量，NORMAL 和 REWORK 记录的合格都计；返工数量、报废和未完成不计。
6. 制作、捏毛装袋、缝边剪袋都有工序提成；其他岗位没有提成。
7. 报废核验时可以选择“计入责任”和责任制作员工；只有计入责任的报废才计算胶水。
8. 每名制作员工每月有无责任胶水额度；额度独立、不结转、不共享；周工资按周累计占用当月额度。
9. 责任报废胶水超过额度时，按商品冻结胶水单价自动扣减工资；主管可在核定金额中调整。
10. 工资按自然周结算，周一至周日；跨月周按日期所属自然月分别计算胶水额度。
11. 工资参考 = 计时工资 + 工序提成 − 胶水扣款，最低为 0；零金额可以核定，无需发放。
12. 成本按实际完成数量 × 商品/方案冻结预算成本计算，只计工作室承担部分；客户供料价值单列。
13. 成本人工使用商品冻结预算，不等于实发工资；实发工资差异不摊回订单。
14. 成本查询实时计算，不建成本表，不作为会计凭证。
15. 不做现金账户、经营费用、库存、采购、社保个税和会计总账。

## 19. 评审收口

- 本文是 V3 工资与成本模块评审稿，覆盖需求、字段、规则、状态、9 张工资表、0 张成本表、接口、事务、权限、页面和验收；
- 工资和成本拆成两个子域，工资有事实表，成本按查询实时计算；
- 计时、提成和胶水扣款分别有独立参考行，便于逐人核对和追溯；
- 制作岗位任务标准分钟考核、报废不计提成和责任报废胶水扣款已落到规则和验收；
- 工资与考勤、生产、商品、全局和订单只走公开查询，不直接读表；
- 所有金额和成本公式归计算中心；
- 本模块暂无待确认项；
- 评审通过后进入老板看板/报表。

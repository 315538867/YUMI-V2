# V3 页面风格规范

> 文档版本：V3.0  
> 编写日期：2026-10-30  
> 状态：V3 页面风格评审稿；先评审规范与看板原型，通过后再迁移页面

本文是 V3 全站页面的视觉与交互契约。方向参考腾讯云控制台的控制台布局和信息密度，但不复制腾讯或其他品牌的 logo、图标、插画和文案素材。V3 使用自己的产品标识、图标和业务内容。

## 1. 定位

V3 是工作室内部经营管理系统，页面首先服务连续录入、核对和看数，不追求营销页的视觉表现。

整体观感：

- 白色顶栏 + 左侧分组菜单 + 浅灰内容底 + 白色工作卡片；
- 蓝色作为唯一主操作色，状态色只做小面积标签；
- 信息密度高，表格和表单紧凑，一屏尽量看到完整业务；
- 卡片边界清楚，阴影克制，不用大面积渐变和装饰插画；
- 控制台式导航：一级模块 + 分组菜单 + 当前页高亮。

## 2. 与 V2 的关系

- V2 的深绿色图标 rail、绿色强调色和页头排版不继续沿用；
- V3 重新建立 token、外壳和组件规范，不复用 V2 页面级样式；
- 业务字段、表格、表单和操作流程继续沿用已评审的需求；
- V2 的 Element Plus 组件栈继续使用，但外观由 V3 token 和组件样式覆盖；
- 迁移顺序：先老板看板/财务，再工资、订单、生产，最后商品、客户、员工和设置。

## 3. 整体布局

### 3.1 外壳尺寸

| 区域 | 尺寸 | 说明 |
|---|---|---|
| 顶栏 | `56px` | 白色，底部 1px 分隔线 |
| 左侧菜单 | `232px`，收起 `64px` | 白色，分组菜单 |
| 内容最大宽度 | `1600px` | 与现有 1600×900 验收基线一致 |
| 内容内边距 | `24px 32px 48px` | 页面四周留白 |
| 卡片间距 | `16px` | 统计卡、图表、表格之间 |
| 卡片圆角 | `8px` | 工作区卡片 |
| 卡片内边距 | `16px` / `20px` | 表格卡 16，图表卡 20 |

### 3.2 顶栏

- 左侧：产品标识 + 产品名“YUMI 经营管理台”；
- 中部：全局搜索，占 320–420px，接口和范围见平台模块 13.9；
  - 输入至少 2 个字符后触发，输入停止 250ms 再请求，快捷键 `/` 聚焦；
  - 结果下拉按类型分组（订单、客户、商品、员工），每组最多 5 条，有更多时显示“查看全部”并跳转该类型列表页并带上关键词；
  - 没有读取权限的类型整组不显示；某组降级（`degraded`）时在下拉底部提示“部分结果暂不可用”；
  - 只搜编号和名称，不搜电话、地址和成本；输入框占位文案为“搜索订单、客户、商品或员工编号/名称”；
  - 支持方向键和回车选择，`Esc` 关闭，下拉有 `role="listbox"`；
- 右侧：环境标签、帮助、通知、账号头像；
- 顶栏不使用大面积品牌色，白色底 + 1px 底边；
- 当前环境不是生产时，环境标签使用警告色，不能隐藏。

### 3.3 左侧菜单

- 一级菜单按业务分组：工作台、业务、生产、财务、系统；
- 页面归属：工作台（老板看板）、业务（订单、客户、商品）、生产（生产计划、生产记录、员工、考勤）、财务（工资、日常支出、资金流水）、系统（全局设置、账号与角色、审计日志）；员工和考勤归入生产是为了排班与工资核对，不影响各自权限；
- 组标题 11px 弱化文字，菜单项 13px，行高 36px；
- 当前项：浅蓝底 `brand-soft` + 左侧 3px 蓝色指示条 + 蓝色文字；
- 悬停：`surface-hover` 浅灰底，不使用整行蓝色；
- 菜单可收起为 64px 图标模式，收起后通过 tooltip 和 aria-label 显示名称；
- 图标 16px，线性风格，不复制第三方产品图标。

### 3.4 内容区

- 面包屑：模块 / 当前页，12px 弱化文字；
- 页头：标题 20px、说明 12–13px、右侧动作；
- 页头下方先放筛选/日期，再放内容；
- 内容区使用 12 列网格，卡片跨列组合；
- 页面不出现超大标题、整屏渐变背景和装饰性插画。

## 4. 色彩

### 4.1 语义 token

| token | 值 | 用途 |
|---|---|---|
| `--v3-brand` | `#1466e8` | 主按钮、链接、选中态、图表主线 |
| `--v3-brand-hover` | `#0e56c9` | 主按钮悬停/按下 |
| `--v3-brand-soft` | `#eaf2ff` | 当前菜单、选中行、浅色强调 |
| `--v3-ink` | `#1d2129` | 标题、主数值 |
| `--v3-text` | `#4e5969` | 正文、表格内容 |
| `--v3-muted` | `#556070` | 说明、表头、辅助字段（在白底、canvas、surface-hover 上均 ≥ 4.5:1） |
| `--v3-line` | `#e5e6eb` | 卡片、表格、分隔线 |
| `--v3-canvas` | `#f2f4f7` | 页面底色 |
| `--v3-surface` | `#ffffff` | 卡片、顶栏、菜单 |
| `--v3-surface-hover` | `#f7f8fa` | 行悬停、菜单悬停 |
| `--v3-success` | `#067a55` | 已完成、收入、正向（文字用） |
| `--v3-warning` | `#9c4f0a` | 待处理、部分完成、风险（文字用） |
| `--v3-danger` | `#c9323f` | 失败、报废、支出（文字用） |
| `--v3-info` | `#1466e8` | 提示、链接 |

### 4.2 使用规则

- 蓝色只用于主操作、链接、选中和图表主线；
- 状态色只用于标签、图标、金额方向和图表小面积；
- 不整行、整卡铺状态色；
- 正文和背景对比度至少 4.5:1；上表文字色已按白底、`canvas`、`surface-hover` 和各状态浅色底核对；
- 图表线条、图标、状态点等非文字元素对比度至少 3:1，可使用更亮的图表色（`--v3-success-chart: #0a9a68`、`--v3-warning-chart: #d9650a`、`--v3-danger-chart: #e34d59`），不得用于文字；
- 状态标签的浅色底 token：`--v3-success-soft #e8f7f0`、`--v3-warning-soft #fff3e8`、`--v3-danger-soft #fdecee`，文字用上表文字色；
- 页面禁止写死色值，必须引用 token；
- 图表颜色顺序：蓝、青、橙、红、灰，最多 5 个系列。

## 5. 字体

| 层级 | 字号/行高 | 用途 |
|---|---|---|
| 页面标题 | `20/28` | 当前工作区标题 |
| 卡片主数值 | `28/36` | 看板核心金额 |
| 区块标题 | `15/22` | 卡片头、图表标题 |
| 正文 | `13/20` | 表格、表单、说明 |
| 辅助文字 | `12/18` | 表头、说明、单位 |
| 微文字 | `11/16` | 标签、时间、注释 |

- 中文使用系统无衬线字体；
- 金额、数量、日期使用等宽数字 `font-variant-numeric: tabular-nums`；
- 标题字重 600，正文 400，强调 500；
- 不使用第三方字体和网络字体。

## 6. 间距、圆角与阴影

| 类别 | 值 |
|---|---|
| 间距 | `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40` |
| 圆角 | `2 / 4 / 6 / 8px`；按钮 4，卡片 8，标签 2 |
| 卡片阴影 | `0 1px 2px rgba(29, 33, 41, 0.04)` |
| 弹层阴影 | `0 8px 24px rgba(29, 33, 41, 0.12)` |
| 分隔线 | `1px solid var(--v3-line)` |

- 间距使用 4 的倍数；
- 卡片之间 16px，卡片内区块 16/20px；
- 表格行高 40px，表头 36px；
- 控件高度 32px，主按钮 32/36px；
- 不使用大圆角、胶囊按钮和浮夸阴影。

## 7. 组件规范

### 7.1 页头

- 面包屑在上，标题和说明在下，动作靠右；
- 标题 20px，不使用 28px 以上大标题；
- 动作最多一个主按钮，其他为次按钮/文字按钮；
- 页头与内容之间 16px。

### 7.2 筛选条

- 位于卡片内部顶部，控件高度 32px；
- 日期范围、状态、关键词按业务顺序排列；
- 主筛选动作靠左，重置和高级筛选靠右；
- 不把筛选做成大表单。

### 7.3 统计卡

- 2×2 或 4 列网格；
- 标签 12px、主数值 28px、辅助说明 12px；
- 本期统计卡不带环比/同比和小趋势线；接口补充对应字段并评审通过后再启用；
- 主数值使用等宽数字；
- 不使用大面积蓝色卡底，统一白卡。

### 7.4 表格

- 表头 36px、11–12px、弱化文字、浅灰底；
- 行 40px，正文 13px；
- 行悬停 `surface-hover`，选中行 `brand-soft`；
- 金额列右对齐，状态列居中或左对齐；
- 表格撑满卡片宽度，不在表格外再套一层边框；
- 分页在卡片底部，左显示总数，右显示页码和每页条数。

### 7.5 按钮

| 类型 | 外观 |
|---|---|
| 主按钮 | 蓝底白字，圆角 4，高度 32 |
| 次按钮 | 白底灰边，悬停浅灰底 |
| 文字按钮 | 蓝色文字，无边框 |
| 危险按钮 | 红字/红边，二次确认 |
| 图标按钮 | 32×32，悬停浅灰底，必须有 aria-label |

- 一个区域最多一个主按钮；
- 破坏性操作不与主操作并排突出。

### 7.6 标签与状态

- 状态标签使用浅色底 + 状态色文字，圆角 2；
- 成功、警告、失败、处理中、已作废各有固定文案；
- 颜色不是唯一表达，标签必须带中文文字；
- 金额方向用正负号和颜色共同表达。

### 7.7 表单

- 表单标签在上，控件高 32px；
- 两列/三列网格，长文本占整行；
- 字段错误在控件下方内联显示；
- 不使用抽屉承载长表单；短命令用对话框；
- 主操作固定在表单底部右侧。

### 7.8 图表

- 折线/面积图用于趋势，柱状图用于对比，环形图用于构成；
- 网格线 `line` 色，弱化；
- 主线蓝色，辅助线青色/灰色；
- 图例在图表上方右侧，文字 12px；
- 不显示 3D、阴影和装饰性渐变；
- 空数据时显示“暂无数据”，不画假线。

### 7.9 弹层

- 短命令使用对话框，宽度 480–560px；
- 复杂编辑使用整页，不使用抽屉；
- 对话框标题 16px，正文 13px，底部按钮右对齐；
- 打开后焦点进入弹层，关闭后回到触发按钮。

## 8. 老板看板关键页

### 8.1 结构

```text
顶栏
左侧菜单
内容区
├─ 面包屑：财务 / 老板看板
├─ 页头：老板看板 + 日期范围 + 刷新
├─ 指标卡：应收 / 商品毛利 / 经营利润 / 现金净额
├─ 趋势卡：应收、商品毛利、经营利润、现金净额（折线/面积）
├─ 结构卡：商品成本、实发工资、日常支出、未收应收
├─ 商品排行：按商品毛利降序
└─ 资金流水：最近收付款和支出；流水投影过旧时在此提示并链接到资金流水页
```

### 8.2 指标

- 应收：期间订单应收金额；
- 商品毛利：应收 − 商品成本（含标准人工）；
- 经营利润：应收 − 非人工商品成本 − 实发工资 − 日常支出；
- 现金净额：收款 − 退款 − 工资发放 − 日常支出；
- 毛利和经营利润率显示在卡片副行；
- 指标卡副行显示毛利率、经营利润率等财务模块已返回的比率；本期看板接口不返回环比、同比，卡片不显示环比同比，也不画小趋势线（趋势只在趋势卡里展示）；

### 8.3 交互

- 日期范围支持本月、上月、近 7 天和自定义；
- 刷新重新读取看板；
- 看板不提供重建入口；重建在资金流水页由 `finance.cash.rebuild` 权限控制；
- 商品排行可点击进入商品或订单；
- 资金流水可点击查看来源详情；
- 页面只读，不提供新建、编辑、删除和重建。

## 9. 交互与状态

- 加载态覆盖数据区域，不整页白屏；
- 失败时保留上次数据并提供重试；
- 空态说明“暂无数据”和下一步动作；
- 筛选条件与 URL 同步，刷新不丢；
- 成功提示只出现一次，失败不能伪装成功；
- 破坏性操作二次确认，写明对象和影响。

## 10. 无障碍

- 所有输入有可见标签或 aria-label；
- 键盘可完成主要流程，焦点可见；
- 弹层焦点管理和 Esc 关闭；
- 图标按钮有中文 aria-label；
- 表格表头与数据列语义正确；
- 颜色不作为唯一状态表达；
- 对比度至少 4.5:1。

## 11. 迁移规则

- 先落 V3 token 和外壳，不直接改业务页；
- 页面不得写死颜色、字号、圆角、间距；
- 共享组件优先，页面只写独有布局；
- 迁移顺序：老板看板/财务 → 工资 → 订单 → 生产 → 商品/客户/员工/设置；
- 每迁移一页，同步更新设计规范、截图和视觉回归基线；
- V2 页面未迁移前不混用 V3 外壳，避免半套风格。

## 12. 不复制品牌素材

- 不使用腾讯云或其他产品的 logo、图标、插画、截图和文案；
- 不复制第三方控制台的页面结构细节到像素级；
- 只参考控制台的信息架构、密度、色彩层级和交互习惯；
- 产品标识、图标和图表由 YUMI 自己维护。

- [ ] 全站使用 V3 顶栏、左侧分组菜单和浅灰内容底；
- [ ] 主操作只用蓝色，状态色只做小面积；
- [ ] 页面标题不超过 20px，不使用大标题；
- [ ] 表格行高 40px、表头 36px，金额右对齐；
- [ ] 指标卡、趋势图和表格在同一内容网格内；
- [ ] 页面不写死颜色、字号、圆距和间距；
- [ ] 加载、失败、空态都有明确表现；
- [ ] 键盘、焦点、aria-label 和对比度通过检查（文字 4.5:1，非文字 3:1，用实际 token 值计算）；
- [ ] 不出现腾讯或其他品牌的 logo、图标和文案；
- [ ] 老板看板四个指标和三类口径与财务文档一致。

# 静态数据与商品字段调整方案（评审稿）

日期：2026-09-24  
修改人：chen  
状态：**已评审并实施**（2026-09-24；2026-09-25 追加 §13）；§1–§11 由任务 2.21–2.27 落地，§12 追加口径的缝边默认值与 6 分钟档位由任务 2.24 落地，实施与证据见 `openspec/changes/build-yumi-v2-order-fulfillment/tasks.md`。

> ⚠️ **现行口径以 §13（2026-09-25）为准**：缝边种类改为「标准分钟」、人工费由全局「时薪 + 制品有效工时率」派生、三类标准分钟统一为整数、员工工种去掉启用状态、Flyway 压缩为单一基线。§1–§12 为历史评审记录，其中「缝边种类 = 成本单价」「档位分钟允许小数」「工种可停用」「V4/V5/V6 分文件」的描述**已被 §13 取代**。

## 1. 目标与决策

三件事：

1. **统一"选标准时间"**：商品侧的星级与包装档位都是"从系统内置静态数据里选一条，带出标准分钟"，只有人工费的系数不同。
2. **缝边移出商品、落到订单（商品只提供默认值）**：缝边是订单里的**定制服务**，不是产品属性。商品侧剔除缝边数量与缝边成本，只保留「默认缝边剪袋类型 + 缝边价格」作为订单缝边定制的默认值；订单明细行上"选缝边种类、填数量、填收费"，并可覆盖商品默认值。
3. **全局口径字段收回全局**：胶水损耗率、日常杂费、房租水电由"全局默认 + 商品可改"改为**全局只读**；装箱人工费、运输包装费保持"全局默认 + 商品可改"；**包装提成新增为全局默认值**（对应真实核算表的"打包提成"参数），商品表单预填、可改。

配套决策：

- 新增「静态数据」概念：**类别由系统预置、code 定死，类别不可增删改名**；类别下的条目按类别分别管理。
- 设置页改为 Tab 结构，「静态数据」Tab 下先是类别列表，点「编辑」用**弹窗**管理该类别的条目。
- 包装提成从档位挪到**全局默认值 + 商品可改**；包装档位只提供标准分钟。

## 2. 现状盘点

| 项目 | 现状 | 判定 |
| --- | --- | --- |
| 制品星级 | `star_levels`（名称唯一 + 标准分钟 1–360），设置页表格可增改删、被商品引用禁删；商品按 id 引用并快照名称/分钟 | 已是"选标准时间"，保留 |
| 缝边 | `products.seam_minutes`（商品手填 scale3）、`seam_default_fee`（商品手填）、`seam_labor_cost`/`seam_reference_fee`（派生，单列不进总成本）；无全局缝边目录 | **整体移出商品，改到订单明细行** |

| 商品全局字段 | 胶水损耗率、日常杂费、房租水电：全局有默认值、商品表单**可改** | 改为全局只读 |

## 3. 目标模型

### 3.1 静态数据

| 类别 | 系统 code | 条目来源 | 条目字段 | 被谁引用 |
| --- | --- | --- | --- | --- |
| 制品星级 | `STAR_LEVEL` | 用户自建 | 名称（唯一）+ 标准分钟（1–360 整数） | 商品（快照名称/分钟） |
| 包装档位 | `PACKAGING_TIER` | 用户自建 | 名称（唯一）+ 标准分钟（0–999） | 商品（快照名称/分钟） |
| 缝边种类 | `SEAM_TYPE` | 用户自建 | 名称（唯一）+ **标准分钟**（整数 1–360；见 §13.1，原为成本单价） | **订单明细行**（决策方）+ **商品默认值**（商品只存默认值指针与标准分钟快照，不存缝边数量/成本） |
| 员工工种 | `WORK_TYPE` | **系统预置 4 条** | **code 定死**（`MAKING`/`PACKING_BAG`/`SEAM_CUTTING`/`OTHER`）+ 名称可改（启用状态已于 §13.5 删除） | 员工档案、员工资格校验、后续生产与核验 |

统一规则：

- 类别是系统常量，接口只按 code 读取，不提供类别增删改名。
- 条目：星级/包装档位/缝边种类由用户增删改，**被引用时禁删**（沿用 `CONFLICT_REFERENCED`；缝边种类的引用方是订单明细行与商品默认值）；工种只允许改名，不允许新增或删除（§13.5 起不再有启用状态）。
- 条目名称在各自类别内唯一（沿用 `CONFLICT_DUPLICATE`）；改名/改数值**不回溯**既有商品或订单快照。
- 所有增删改写入变更日志（`entity_type` = `STAR_LEVEL`/`PACKAGING_TIER`/`SEAM_TYPE`/`WORK_TYPE`）。

### 3.2 商品字段表

| 字段 | 归属 | 现在 | 改后 |
| --- | --- | --- | --- |
| 商品名称 | 商品 | 可改 | 不变 |
| 制品星级 | 商品选（标准时间） | 选星级 | 不变 |
| 包装档位 | 商品选（标准时间） | 选档位（含提成） | 选档位（只提供标准分钟） |
| 包装提成 | 全局默认 + 商品可改 | 挂在档位上 | **移到全局默认值**（`packaging_commission_default`），商品表单预填、可改 |
| 销售单价 | 商品 | 可改 | 不变 |
| 商品克重 | 商品 | 可改 | 不变 |
| 胶水损耗率 | 全局 | 全局默认 + 商品可改 | **全局只读** |
| 装箱人工费 | 全局默认 | 全局默认 + 可改 | 不变 |
| 运输包装费 | 全局默认 | 全局默认 + 可改 | 不变 |
| 日常杂费 | 全局 | 全局默认 + 商品可改 | **全局只读** |
| 房租水电费 | 全局 | 全局默认 + 商品可改 | **全局只读** |
| 模具摊销费 | 商品 | 可改 | 不变 |
| 商品说明 | 商品 | 可改 | 不变 |
| ~~缝边数量 / 缝边成本~~ | — | 商品字段 | **整体移除**（商品不保存缝边数量与缝边成本，见 §3.4） |
| 默认缝边剪袋类型 | 商品 | 无 | **新增**：从 `SEAM_TYPE` 选择，可空＝默认不缝边剪袋；新建订单明细时作为缝边定制默认值 |
| 缝边价格（元/件） | 商品 | 无 | **新增**：订单缝边收费的默认值，订单可改；不进入商品成本 |

"全局只读"= 商品表单只展示当前全局值、不可编辑；保存时由服务端取当前全局值并**冻结进商品快照**（因此商品重新保存会随当时的全局值变化，不重新保存则保持旧快照）。

### 3.3 公式口径变更

| 标识 | 现在 | 改后 |
| --- | --- | --- |
| FP-PROD-08 包装人工费 | `档位标准分钟 × 0.25 + 档位提成` | `档位整数标准分钟 × (时薪 ÷ 60) + **商品提成**`（见 §13.2） |
| FP-PROD-09 缝边单件成本 | `商品手填缝边分钟 × 0.25` | **移出商品分类**，随订单实现 |
| FP-PROD-10 缝边参考收费 | `缝边成本 ÷ 0.7` | **移出商品分类**，随订单实现 |
| 其余 FP-PROD-01..07、11..19 | — | 不变（星级仍是制作标准时间，8h/6h 产量与星级人工费口径不变） |

商品的 `totalCost`/`referencePrice`/利润**不受影响**：缝边原本就单列、不进总成本。

### 3.4 订单侧缝边口径

- 挂在**订单明细行**：每条明细可选一个缝边种类 + 填数量（**可小于明细数量**，如 100 件里 30 件要缝边）+ 填收费单价。
- 选中缝边种类后**带出该种类的单件人工成本作为提示**（= 标准分钟 × 全局时薪 ÷ 60，见 §13.1）；收费单价**不自动等于**成本价，由管理员手填/修改。
- **缝边成本 = 单件缝边人工成本（= 标准分钟 × 全局时薪 ÷ 60，允许 0）× 缝边数量，计入订单成本**；缝边收费 = 手填收费单价 × 缝边数量，计入应收。
- 订单利润按 `应收 −（商品成本 + 缝边成本）` 计算，缝边成本与商品成本**分列可见**。
- 缝边种类的删除守卫为"被订单明细行或商品默认值引用时禁删"。
- **商品只提供默认值**：商品保存「默认缝边剪袋类型」（可空＝默认不缝边剪袋）与「缝边价格（元/件）」，新建订单明细时作为缝边定制的默认值，订单侧仍可改；商品不保存缝边数量与缝边成本，商品自身总成本与参考售价按**不缝边剪袋**口径保存，试算与详情另给「缝边剪袋变体」单列展示（见 §12）。
- 订单侧缝边公式（数量 × 单价）随阶段三实现，登记到 `calculation/order` 分类；商品侧缝边剪袋变体预算属商品分类（`FP-PROD-20/21`）。

## 4. 数据库变更（改写早期迁移为最终结构）

**决策**：开发期未上线，**不改写历史数据**，直接**改写早期迁移为最终结构**，然后清库重建（不做 V6 追加，不留 ALTER 痕迹）。

改写范围：`V4__catalog.sql`（目录表结构）与 `V5__static_data_seed.sql`（静态数据种子）。**2026-09-25 更新**：原 V1–V14 已按用户要求压缩为**单一基线** `V1__yumi_v2_schema.sql`（见 §13.6）。

最终结构：

| 表 | 变更 |
| --- | --- |
| `star_levels` | 不变（`name` 唯一 + `std_minutes` INT） |
| `seam_types` | **新增**：`name`（唯一）+ `std_minutes INT UNSIGNED`（见 §13.1，原为 `cost_price`）+ `version` + 审计列 |
| `packaging_tiers` | **去掉 `commission`**：只保留 `tier_name`（唯一）+ `std_minutes DECIMAL(9,3)` |
| `products` | **删除 `seam_minutes`/`seam_labor_cost`/`seam_default_fee`/`seam_reference_fee`**；新增缝边默认值列 `seam_type_id`（可空 FK → `seam_types.id`，空＝默认不缝边剪袋）+ `seam_type_name`（名称快照）+ `seam_std_minutes`（标准分钟快照）+ `seam_unit_cost`（单件缝边人工成本快照，非空默认 0；§13.1 前名为 `seam_type_cost_price`）+ `seam_fee`（缝边价格，非空默认 0）；`packaging_commission DECIMAL(19,4) NOT NULL DEFAULT 0.0000` 语义改为**商品自身提成**；其余列不变 |
| `work_types` | **新增**：`code`（唯一，系统固定）+ `name`（唯一，可改）+ `version` + 审计列（原 `active` 已于 §13.5 删除） |
| `employee_work_types` | 关系列由 `work_type VARCHAR` 改为 **`work_type_id` FK → `work_types.id`**（唯一键改为 `(employee_id, work_type_id)`） |
| `catalog_settings` | 不变（7 个全局值） |

种子数据（`V5`）：

- 星级 5 条（一星 5 / 二星 10 / 三星 15 / 四星 20 / 五星 30）不变。
- 工种 4 条新增：`MAKING`/制作、`PACKING_BAG`/捏毛装袋、`SEAM_CUTTING`/缝边剪袋、`OTHER`/其他。
- 包装档位**预置 1 条「6 分钟档」**（对应真实核算表固定的「6 分钟 × 时薪 ÷ 60 + 商品提成」），其余档位由用户自建。
- 缝边种类**不预置**（用户自建）。

## 5. 接口变更

静态数据（统一按类别 code 寻址）：

- `GET /api/settings/static-data` → 类别列表 `[{code, name, itemCount}]`
- `GET /api/settings/static-data/{code}` → 该类目条目 `[{id, code?, name, stdMinutes?}]`（星级/档位/缝边都给整数 `stdMinutes`；工种给 `code`；无 `costPrice`/`active`，见 §13）
- `POST /api/settings/static-data/{code}/items`、`PATCH .../items/{id}`、`DELETE .../items/{id}` → 条目增改删（工种不支持 POST/DELETE，只支持 PATCH 改名/启停）

商品：

- 入参：移除 `seamMinutes`/`seamDefaultFee`；新增 `packagingCommission`、`seamTypeId`（默认缝边剪袋类型，可空）与 `seamFee`（缝边价格）；编辑清空默认缝边剪袋类型用 `clearSeamType=true`（PATCH 中 `null` 与"未提供"无法区分）；`lossRatePercent`、`dailySundriesFee`、`rentUtilitiesFee` 不再接受（服务端一律取全局）
- 出参：新增 `packagingCommission`（语义为商品提成）、`seamTypeId`/`seamTypeName`/`seamTypeCostPrice`/`seamFee`（缝边默认值与快照）与 `seamBudget`（缝边剪袋变体预算，未选默认缝边剪袋类型时为 `null`）；移除缝边数量与缝边成本字段；全局只读字段照常回显当前快照值
- 试算入参/出参同步（试算与保存共用同一解析入口，仍只读），出参同样返回 `seamBudget`

员工：

- `workTypes` 由名称改为 **code**（`["MAKING","SEAM_CUTTING"]`）；响应返回 code 与名称；资格校验入参同样按 code

订单（后续阶段实现，本轮只定契约方向）：

- 订单明细行新增缝边定制：缝边种类 id、数量、收费单价；响应含带出的成本单价供提示

## 6. 页面变更

- `/settings` 改为 Tab：「单价与默认值」（现有 7 个全局值表单）｜「静态数据」
- 「静态数据」Tab：类别列表（类别名 / 系统 code / 条目数 / 操作「编辑」）；点「编辑」弹出该类别的条目管理弹窗（列表 + 新增/编辑/删除，被引用禁删提示；工种为改名/启停）
- 商品表单：移除缝边数量/缝边成本字段；包装档位改为下拉选择并新增包装提成输入；新增「默认缝边剪袋类型」下拉（取 `SEAM_TYPE`，可清空＝默认不缝边剪袋）与「缝边价格（元/件）」输入；全局只读字段以纯文本展示当前全局值，不渲染输入框
- 商品预估面板：单件总成本/参考售价标注「不缝边剪袋」，另加「缝边剪袋变体（含缝边成本，单件）」分组展示缝边剪袋变体总成本与参考售价；未选默认缝边剪袋类型时缝边剪袋变体显示 `—` 并说明"默认不缝边剪袋"
- 员工页：工种展示与选择改为"显示名称、提交 code"
- 订单明细（后续实现）：缝边种类选择 + 数量 + 收费单价（带出成本价提示）

## 13. 追加口径（2026-09-25，用户提出 4 项）

### 13.1 缝边种类改为「标准分钟」，成本由全局时薪派生

- `seam_types.cost_price`（元/件）→ **`std_minutes`（标准分钟/件）**，与制品星级、包装档位完全同构：三类静态数据都只提供「标准时间」，人工费一律由全局时薪派生，不再各自携带金额。
- 单件缝边人工成本 = 缝边标准分钟 × 全局时薪 ÷ 60（scale4 HALF_UP）。
- 缝边**收费**不变：商品「缝边价格（元/件）」预填、订单明细行可改，与成本无关。
- 商品侧列改为两列：新增 **`seam_std_minutes INT UNSIGNED NULL`**（所选缝边种类的标准分钟快照，用于「与当前全局不一致」提示），原 `seam_type_cost_price` 改名 **`seam_unit_cost DECIMAL(19,4)`**（单件缝边人工成本快照 = `seam_std_minutes × 保存当时全局时薪 ÷ 60`，冻结不回溯）。商品缝边变体预算 = 不缝边剪袋总成本 + `seam_unit_cost`（`FP-PROD-20/21` 表达式不变，取数改为派生值）。
- 订单侧 `order_items.seam_unit_cost` 来源改为派生值（`OrderItemResolver` 不再读种类的金额字段），`FP-ORDER-04` 表达式不变。

### 13.2 新增两个全局参数：时薪 + 制品有效工时率

新增全局键：

| 键 | 含义 | 预置值 |
| --- | --- | --- |
| `hourly_wage` | 时薪（元/小时） | **15.000000** |
| `workday_hours` | 工作日小时数（小时/天） | **8.000000** |
| `making_effective_hour_rate` | 制品有效工时率（0–1，工作日中可用于制品的产出比例） | **0.750000** |
| `target_margin_rate` | 目标利润率（百分数，30 = 30%） | **30.000000** |

预置值等于当前硬编码效果（`MINUTE_RATE = 0.25 元/分钟`、`LABOR_BASE = 120 元`、`360 分钟`），若预置 0 会让三类人工费全部归零，故取现有效值而非 0。

- **制品星级**：单件制品人工费 = (时薪 × 工作日小时数) ÷ 有效工时产量，其中 **有效工时产量 = `floor(工作日小时数 × 60 × 制品有效工时率 ÷ 星级标准分钟)`**；另有参考列 **工作日标准数量 = `floor(工作日小时数 × 60 ÷ 星级标准分钟)`**（不参与人工费）。用户口径：**正常工作时间由「工作日小时数」给出，但星级只影响制品工序，而制品工序不可能排满整个工作日，故按有效工时产出计标准产量**。默认值（8 小时、0.75）下 = `floor(360 ÷ 星级分钟)`、`120 ÷ 该产量`，与现行逐位一致。
- **包装档位**：单件包装人工费 = 档位标准分钟 × 时薪 ÷ 60 + 商品包装提成（`FP-PROD-08`）。
- **缝边**：单件缝边人工成本 = 缝边标准分钟 × 时薪 ÷ 60（见 13.1，`FP-PROD-20/21`、`FP-ORDER-04`）。
- **参考售价**（不区分工序）：参考售价 = 单件总成本 ÷ (1 − 目标利润率)（`FP-PROD-15`；目标利润率 30% 时即 ÷ 0.7）。

**制品有效工时率只作用于制品（星级）人工费**（2026-09-25 用户明确「只针对制品」）：包装与缝边是"按分钟计件"的工序人工，直接用 `标准分钟 × 时薪 ÷ 60`，不乘有效工时率。因此默认值下包装（6 分钟 → `6×0.25+提成`）与缝边（5 分钟 → `1.25` 元）数字全部不变。

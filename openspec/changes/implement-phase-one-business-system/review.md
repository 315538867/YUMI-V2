## 2. 业务口径回归核对

| 既定规则 | 本轮核对结果 |
|---|---|
| 逐人工资与处理明细 | 系统参考仍计算；明细可空/可为零，最终工资独立填写，不自动相减、不强制实际等于参考。10+20 的处理项配 1000 工资仍为 1000 应付/人工成本 |
| 胶水免扣 | 统一自然月完整来源、历史成员、4 位重量分配及逐行金额舍入；不因拆工资期间重复减免、不结转余额 |
| 责任和去向 | 返工无责任；报废责任与物理去向分开，同一报废转线下只退出一次；移交后仅独立责任更正，不恢复库存 |
| 其他任务 | 不绑生产来源、不改变制品和材料来源；有商品才按冻结计件依据发布劳动；小组整体分钟不再除效率 |
| 历史依据 | 最终供料覆盖和历史标准用于成本；缺失不回填当前价格，未发生不伪造零成本；当前配置不覆盖历史核定 |
| 收付入口 | 订单/售后内操作收退款，现金命令归 cash；payroll 只提供内部支付参与，不直接改已付状态 |
| 日期和凭证 | 用户选择合法业务日期归月；所有收付款凭证可选且随本条，不另建凭证池 |
| 工资退回和冲销 | 真实部分退回按原员工分配上限，现金按退回日期，不自动减人工成本；错误整笔冲销有独立互斥与反向保护 |
| 成本与报表 | 实际人工取核定及人工差额，不取参考处理项；明确成本分摊，不把现金净额叫利润；重建报表不修改业务事实 |
| 一期边界 | 仍无资金账户、员工账号绑定、材料库存采购、线下库存销售管理及服务端草稿；九顶层模块不变 |
